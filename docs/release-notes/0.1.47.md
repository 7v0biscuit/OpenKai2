# v0.1.47

Save management, capsule unlocks and music playback improvements, preserving the
v0.1.46 character-preview and import changes.

- Saves now switches between game saves and backup history. Select one backup
  to restore, double-click it, or select several to delete. Select all, clear
  selection, Ctrl/Shift selection and the Delete key are supported. Restores
  and deletion ask for confirmation; deleting game saves keeps a recovery copy.
- Backups are read back and checked before they appear in the list, sorted by
  their actual creation time and labeled with seconds. Restoration retains the
  previous card before installing the selected snapshot.
- Unlock all now grants all 404 supported capsules, including skills, fusions,
  breakthrough capsules and tournament levels, along with the original roster
  and stages. Invalid and unused item slots remain untouched. The previous save
  is backed up and both checksums are verified. Load the edited save in the game.
- SoundTouch replaces the custom music stretcher, keeping stereo phase and pitch
  during uneven or slower game execution. Rate tracking accounts for startup
  buffering and avoids repeatedly draining and refilling the stream. Full-speed
  PCM remains unchanged; per-core audio diagnostics now record stop requests.
- Signed EE branches inspect the complete low 64-bit register. The previous
  32-bit comparison corrupted the game's software-double angle arithmetic.
  Original arithmetic regressions cover 256 cases. This addresses an identified
  cause of incorrect movement; Dragon World progression and character poses
  still need gameplay validation.

- Disc reports compare Budokai 3 and Budokai 2 character models piece by
  piece, to find why imported Budokai 3 models are drawn black. A Budokai 2
  character copied into the same kind of character ID looks normal, so the
  black comes from the Budokai 3 files. For Krillin's and Supreme Kai's first
  models the report gives a check value for the whole mesh and texture pack,
  each mesh block and each texture's pixels and palette (equal values mean
  equal data), the first 512 bytes of the second mesh block and the last 128
  bytes of the texture pack. Please send a Budokai 3 and a Budokai 2 report.

Stable 60 FPS, complete Dragon World progression and all music playback are not
yet verified. Dialogue and some confirmation panels can remain invisible.
The original Budokai 2 USA ISO is required; game files are not included.
