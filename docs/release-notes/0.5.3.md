# v0.5.3

Animated names for the developer profile and steadier HD textures.

- **Animated developer names.** The [DEV] profile can show its name as a
  rainbow cycle, a rainbow wave, a golden shimmer, a ki pulse or silver frost
  in the Players and Friends lists, menus and profile pages. Each effect is
  signed with the developer key and checked by every launcher, so no other
  profile can use or fake one, and the options only appear when that key is
  installed.
- **Steadier HD textures on paletted textures.** When the game reloads a
  palette without changing it, the launcher no longer throws away its palette
  and HD texture lookups for it, so paletted HD textures are not looked up
  again for nothing.

Both players need v0.5.3 to play together online.

Download **OpenKai2.exe** for the portable app, **OpenKai2-windows-x64.zip** to
extract manually, or **OpenKai2-Setup.exe** to install. The original Budokai 2
USA ISO is required at every launch. Checksums are in **SHA256SUMS.txt**.
