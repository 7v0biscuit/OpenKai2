# v0.1.79

Music off, permadeath without restarting, and a tidier Splits panel.

## Audio

- **Music** in Settings > Game can be turned off. Only the game's music
  tracks go quiet; voices, sound effects and videos still play. It applies the
  next time the game starts.

## Speedrun mode

- When a permadeath run ends, **GAME OVER** shows and the game goes straight
  back to the main menu. The window no longer closes and reopens.
- The Splits panel lists best run, sum of best and possible save as labelled
  totals under the list, shows the selected split by name and no longer
  overlaps its hint text. The All rules button is gone.

## Save states

- F5 now works at the main menu after the opening movie is skipped. A movie
  that has stopped showing pictures no longer blocks saving.

The original USA ISO is required.
