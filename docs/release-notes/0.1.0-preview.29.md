This preview fixes the missing memory-stream destructor reached after movie
playback. The Preview 28 log shows normal worker priorities and no accumulated
wakeups, then stops at the original movie teardown call from `0x00183C4C` to
`0x0016CDA0`. retail testing shows a black screen after the movie and improved but
still slow playback.

Translation now covers all nine methods in the SJMEM memory-stream interface,
preserving its reserved slots. The methods and table are verified against the
supported executable. The regression runs the original logged teardown
continuation through stream destruction and the remaining caller cleanup,
checks caller state and pool bounds, and exercises stream construction, byte
counts, acquisition, return, consumption, reset, peek, and error callbacks.
Windows publication requires this check in the installed application.

Pixel-aligned bilinear samples now avoid redundant interpolation while preserving
all four texture reads and their cache behavior. Pixel comparisons cover aligned
and fractional coordinates, all color/alpha channels, texture-page boundaries,
and wraparound. The aligned 512x448 benchmark dropped from about 18 ms to 14 ms
per draw on the development machine; this is not a retail frame-rate result.

Bounded timing reports now measure MPEG decoding, output copying, GS texture
uploads, and textured sprite drawing. The new reports will help locate the
remaining slowdown on the target system without changing guest clocks or
frame selection.

Retail playback speed, the transition to the title screen, audio synchronization,
and gameplay remain unverified. The original USA ISO is required at every launch.
