Restore the missing character aura callbacks and reduce repeated palette work in the CPU renderer.

## Changes

- Register all six methods from both aura-update tables, including `0x00211FC0`, and verify their complete original instructions and reserved slots.
- Run the original primary and secondary selectors in 576 bounded cases covering both characters, inactive objects, matrix copies and scaling, progress, special states, completion, saved registers, and stack guards.
- Prepare indexed palette colors once for reuse across pixels and filter taps. Match the actual latched CLUT contents and all lookup state; preserve skipped palette loads and transparency behavior.
- Share prepared colors with raster workers. Keep small draws with cold palettes on scalar lookup, and resolve only 16 distinct colors for four-bit textures.
- Add 50 serial/parallel reference fixtures covering fourteen draws each, all indexed texture formats, palette state changes, reset, reinitialization, and multiple backend instances.
- Report palette cache hits, builds, and scalar fallbacks in startup diagnostics.
- Add the optional `openkai2_palette_bench` target for repeatable draw timings and complete VRAM checksums.

Serial fixtures with reusable palettes measured approximately 6–16% lower draw times using three-run medians. Parallel results were mixed, including slower cases. Frequently changing palettes can still add overhead on tiny draws. All measured VRAM hashes matched; these synthetic timings do not establish an end-to-end FPS improvement.

## Status

The new entries address the reproduced missing aura-update call during battle setup. Complete battle loading, gameplay, and stable 60 FPS remain unverified. The movie decoder and audio implementation are unchanged.

The original Budokai 2 USA ISO is required at every game launch. Game files are not included.
