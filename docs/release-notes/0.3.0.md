# v0.3.0

Online matches that start from exactly the same state.

- Online: matches always use PS2 disc timing, whatever **PS2 load times** is
  set to. Before, two players with different settings could drift out of sync.
- Online: the disc drive's position and the game's random numbers are now sent
  with the starting state, so both games begin from the same point.
- Save states: loading a state now continues exactly as the game would have if
  it had kept running. Save states made by earlier versions cannot be loaded.
- Rollback netcode is in development. This version adds the first step:
  snapshots that store only the memory that changed each frame, checked in
  game by rolling back and replaying frames. Matches still run in lockstep.

Both players need v0.3.0 to play together.

Download **OpenKai2.exe** for the portable app, **OpenKai2-windows-x64.zip** to
extract manually, or **OpenKai2-Setup.exe** to install. The original Budokai 2
USA ISO is required at every launch. Checksums are in **SHA256SUMS.txt**.
