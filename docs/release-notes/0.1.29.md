# v0.1.29

Fix story-mode text and board movement, time disc reads like a PS2, and refresh the launcher.

- Truncate EE float-to-int conversions toward zero and saturate them by sign,
  as the console does. Rounding to nearest made the UI keyframe sampler read
  past the end of its table, which hid Dragon World dialogue text and the
  Yes/No options, and made board movement wrap its path time backwards so
  characters walked past their destination.
- Time CD/DVD reads with the PS2 drive's seek and constant-angular-velocity
  transfer rates, measured in emulated IOP cycles, so loads take as many game
  frames as on a console. `OPENKAI2_DISC_TIMING=instant` restores immediate
  reads for development.
- Read back and re-upload only the VRAM pages a local-to-local or
  local-to-host transfer touches instead of all 4 MiB.
- Reduce the launcher to Play, Saves and Settings, with update options in
  Settings. Rewrite its labels and messages, set titles in Bangers (SIL OFL
  1.1), and add a two-star Dragon Ball icon to the executable, windows,
  portable launcher and installer.

The original USA ISO is required. Host audio remains off. Story dialogue and
board movement fixes are verified against the game's own animation code and
need in-game confirmation; stable 60 FPS remains under validation.
