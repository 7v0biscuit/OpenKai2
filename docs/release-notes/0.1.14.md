# v0.1.14

Reduce CPU renderer work in textured triangles and sprites while preserving
coverage, draw order, and the existing vector and scene rendering fixes.

- Compile swizzled texture addressing with the CPU renderer. Common 32-bit,
  16-bit, and indexed texture taps can inline address calculation and cache
  resolution. Other texture formats retain the general sampler.
- Interpolate triangle color and texture coordinates in SIMD lanes with the
  original floating-point operation order. Omit unused vertex-color work for
  texture-replacement draws whose texture supplies alpha.
- Apply modulation and highlight texture functions to packed color channels,
  preserving saturation and the selected alpha source.
- Compare 128 original material fixtures with one and four workers, covering
  all four texture functions, alpha sources, color gradients, fixed and
  perspective coordinates, filtering, direct and indexed textures, and
  dependent samples. The checks compare 512 complete VRAM snapshots and run
  in the component suite and packaged executable's self-test.

The original USA ISO is required at every launch. Host audio remains disabled.
Complete matches and sustained 60 FPS remain unverified.
