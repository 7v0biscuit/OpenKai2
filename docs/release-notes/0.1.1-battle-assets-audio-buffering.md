Battle asset relocation, lower IOP scheduling overhead, and buffered PCM output.

## Changes

- Register both BCM animation and BSK skeleton relocation callbacks used after stage selection. Execute the original asset dispatcher in regression checks, including nested pointers, nulls, aliases, and repeat guards.
- Skip empty IOP scheduling periods up to the next known event, share instruction fetches, and defer diagnostic formatting and CPU snapshots.
- Buffer PCM jitter with a 2,048-frame prefill and fade across startup, gaps, and replacement streams. Trim stale queued audio after overflow.
- Report audio underruns and trimmed frames in startup diagnostics.

A two-million-cycle interpreter benchmark improved from 97.24 ms to 65.43 ms for a busy thread and from 67.67 ms to 9.62 ms while idle. Guest cycle and instruction counts matched. These are interpreter measurements, not game-FPS results.

## Status

Complete matches and stable 60 FPS remain unverified. The callback fixes address a reproduced stage-loading failure; complete battle loading still requires retail validation. Slow execution can still cause audio gaps, and full SPU2 voice/effect behavior remains incomplete.

The original Budokai 2 USA ISO is required at every game launch. Game files are not included.
