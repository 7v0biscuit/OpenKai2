This preview fixes overlapping EE callback and bootstrap stacks. The latest
startup log shows the only EE thread becoming dormant with both PC and return
address zero, rather than waiting on a semaphore or event.

The first asynchronous callback stack previously started at the same address as
the bootstrap stack. A callback's saved zero return sentinel could overwrite an
interrupted caller's return address. Callback allocation now leaves the top
64 KiB for the bootstrap stack and stays above the existing guest heap limit.

Regressions reproduce return-frame corruption and a lost continuation on the
previous runtime. They check nested stack separation, reuse, alignment, arena
bounds, and successful resumption through the EE scheduler. The installed
executable also executes an original translated callback during that test.
Release publication requires this self-test to pass on Windows.

The original USA ISO is required at every launch. Full game boot and gameplay
remain unverified; retain `startup.log` when testing this development preview.
