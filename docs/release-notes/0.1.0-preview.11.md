This preview adds diagnostics for the blank window reported after scratchpad
initialization. The latest log passes the previous DMA failure and shows no new
exception before the user closes the window. Its cause remains unidentified.

The runtime now records EE thread states, resume addresses, return addresses,
wait objects, semaphore counts, event flags, and DMA/GIF/GS/VIF activity at 5,
15, 30, and 60 seconds, plus shutdown. Reports use synchronized snapshots and
bounded object lists. A few zero-PC returns retain their dispatch history without
being treated as errors.

Regressions verify that diagnostics preserve a blocked semaphore wait and guest
memory. The executable self-test also runs the original compiled scratchpad bank
save/restore sequence, including DMA synchronization and caller-frame restoration.
Release publication requires these checks to pass on Windows.

The original USA ISO is required at every launch. If startup remains blank, leave
the window open for at least 60 seconds, close it, and retain `startup.log`.
Full game boot and gameplay remain unverified; this is a diagnostic development
preview, not a verified blank-screen fix.
