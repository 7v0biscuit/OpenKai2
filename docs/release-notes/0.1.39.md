# v0.1.39

Disc reports now find Budokai 3's character table.

The first Budokai 3 report showed that Budokai 3 keeps its character names in
a list of their own, instead of in each character's record as Budokai 2
does. So the report found the names but not the records with the characters'
files. The report now also:

- follows the words that point at each name, which finds records that keep
  a pointer to their name, with the fields that look like file numbers;
- lists every character name in the executable with its address;
- shows the first three records of each table word by word;
- lists every entry of the data archives with its first 32 bytes, not only
  the first 24, so Budokai 3's files can be matched with Budokai 2's.

What the Budokai 3 report showed so far:
- Its archives are the same AFS format as Budokai 2's, named `DATA_CMN.AFS`,
  `DATA_USA.AFS` and `ADX_USA.AFS`.
- Its sound is CRI ADX, the same as Budokai 2's.
- Its data files are packed in `#AMB`, `#AMK` and `#SKA` containers. Whether
  Budokai 2 reads them unchanged needs a Budokai 2 report to compare.

To help map Budokai 3, save two reports in the import tool with
**Save disc report…**: one from the Budokai 3 disc and one from the Budokai 2
disc (press **Game disc** first). Characters cannot be imported from Budokai 3
yet.

Not fixed yet: in Dragon World the character can walk off screen, and the
dialogue text and the Yes/No prompt after character select are invisible.

The original USA ISO is required.
