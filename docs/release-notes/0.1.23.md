# v0.1.23

Run VU1 microprograms through PCSX2's microVU native recompiler.

- Reuse compiled vector programs across unchanged uploads. Preserve register
  state, MSCAL/MSCNT continuations, scalar waits, stop flags, and elapsed cycles.
- Assemble wrapped PATH1 packets and synchronize VU memory around host
  callbacks. Report callback errors after native code returns.
- Preserve Windows nonvolatile floating-point registers across native dispatch.
  An independent host-calculation regression fails before this correction and
  passes afterward.
- Retain the original interpreter references and add independent checks for
  flags, loads, matrix transforms, branches, continuation, scalar operations,
  D/T halts, cycle wraparound, packets, code uploads, and callback failure.
- Include pinned PCSX2 sources and their license notices. The EE game functions
  remain statically translated by PS2Recomp.

A Windows-binary replay under Wine matched vector registers, stored data, and
packet bytes for 512 captured dispatches. Across ten warm samples, median
execution time was 22.3 ms with PCSX2's interpreter and 2.15 ms with microVU,
about 90% less execution time. These timings exclude graphics submission and the EE
executor and do not establish game FPS.

The original USA ISO remains required. Host audio remains disabled. Character
pose distortion is still visible, and complete matches and stable 60 FPS remain
unverified.
