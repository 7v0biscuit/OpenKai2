# v0.1.37

A simpler import tool.

- Open the import tool with your game disc already loaded, and start by
  choosing what to do: **Add a character**, **Replace a character** or
  **Copy files**.
- Add or replace a character in three steps: choose a character, choose a spot
  on the select screen or who to replace, and choose where to save. A sentence
  beside **Import** says what will happen. The search box finds characters by
  name, and new mods are named after the character.
- Archive entries, file targets and content types now appear only under
  **Copy files**.

Limits are unchanged:
- The select screen has 29 spots, so an added character replaces the one shown
  in its spot.
- Characters are listed for Budokai 2 USA discs; Budokai 3 discs use
  **Copy files**.

Not fixed yet: in Dragon World the character can walk off screen, and the
dialogue text and the Yes/No prompt after character select are invisible.

The original USA ISO is required. The import tool is verified by launcher
interaction tests and an end-to-end import against the USA executable's
tables. Imported characters need in-game confirmation.
