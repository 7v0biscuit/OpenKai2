# v0.4.6

Smoother heavy fights, better Budokai 3 movesets, and fixes for added characters.

- **Less work per frame in busy fights.** The thread that prepares every draw
  was the bottleneck in scenes with lots of effects. It now spends about half
  as long uploading textures and no longer logs every draw for diagnostics, so
  heavy scenes should drop fewer frames at every graphics setting.
- **Higher internal resolutions are faster.** When only part of a sharper image
  changes, only that part is refreshed instead of the whole image. In a
  recorded fight this was 9% faster at 2x and 19% faster at 3x.
- **Imported Budokai 3 moves line up better.** A Budokai 3 character who is
  also in Budokai 2, such as Vegeta, now uses its own moves for its specials
  instead of Goku's, and every character gets more moves matched to the right
  action. Re-import a character with **Force a new character with its Budokai 3
  moves** to get this.
- **Added characters show the right fight portrait.** An added character in a
  low character ID showed another character's face in the fight HUD; it now
  shows its base character's.
- **Edit Skills sees more than 520 capsules.** A capsule mod with more than 520
  capsules now works in the versus Edit Skills menu. The Skill List, the shop
  and capsule names still stop at 520.

Known issue: added spots on the character select screen still show the name
"Random" and borrow another spot's portrait.

Both players need v0.4.6 to play together online.

Download **OpenKai2.exe** for the portable app, **OpenKai2-windows-x64.zip** to
extract manually, or **OpenKai2-Setup.exe** to install. The original Budokai 2
USA ISO is required at every launch. Checksums are in **SHA256SUMS.txt**.
