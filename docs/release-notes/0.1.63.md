# v0.1.63

A new look for the launcher, plus a few things it should always have done.

- Restyled in Budokai 2's colours: deep night blue with ember orange and gold.
  A faint warm light falls from above the title and a cool one from below the
  sidebar.
- The two-star Dragon Ball on the Play page is drawn smoothly now, glass-lit
  with soft edges, and glows in the banner. The sidebar ball matches it.
- Play, Import and the chosen import task glow; the current page is lit from
  the left of its row. Panels and buttons have quieter borders.
- The status pill is gone; the game's state sits quietly beside the title.
  Coloured tick marks and the outlined circles in the banner are gone too.
- Drop an ISO on the window to use it as your game disc, or, in the import
  tool, as the disc to import from.
- The launcher reopens where you left it, at the same size, and maximised if
  it was.
- F5 starts the game from any page once your disc is verified.
- Lists use dark scroll bars on Windows 10 and 11.

Stage import stays experimental, as in v0.1.62.

Not fixed yet: in Dragon World the character can walk off screen, and the
dialogue text and the Yes/No prompt after character select are invisible.

The original USA ISO is required.
