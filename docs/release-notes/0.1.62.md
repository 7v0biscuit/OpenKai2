# v0.1.62

Brings stage import back, as an experimental feature.

Budokai 3 stages froze the game because their packs hold `#AME` particle
files, which Budokai 2 has no loader for. The import tool now leaves those
files out when it converts a stage, so everything else in the pack is a kind
Budokai 2 loads.

- The import tool's Stages tab imports Budokai 3 stages again, marked
  experimental. An imported stage has no particle effects of its own.
- Stage mods are applied again. The startup log marks each one experimental.
- Stages imported with v0.1.59 still hold the particle files and stay
  skipped. Delete that mod (or remove the stage on the Mods page) and import
  the stage again.
- If a fight on an imported stage doesn't load, remove the stage on the Mods
  page and send the startup log.

Not fixed yet: in Dragon World the character can walk off screen, and the
dialogue text and the Yes/No prompt after character select are invisible.

The original USA ISO is required.
