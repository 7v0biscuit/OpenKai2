# v0.1.71

Smoother, glitch-free tab switching in the launcher.

## Launcher

- The tab label, icon and highlight now move together; the label no longer
  lights up before the highlight reaches it.
- Clicking while the highlight slides finishes the slide at once, so quick
  clicks through the tabs are never delayed.
- The hover box and focus ring no longer flash over the moving highlight.
- Clicking the tab you are already on does nothing instead of redrawing.
- Opening a dropdown during a slide no longer redraws behind it.

## Game

- **F5** explains why when a state can't be saved at that moment, instead of
  doing nothing.

The original USA ISO is required.
