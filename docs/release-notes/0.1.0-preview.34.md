The latest retail log shows successful save writes and closes, followed by a
stalled graphics DMA queue. Movies remain slow and menus run at a reported
2–5 FPS. No parallel drawing batches ran in that session.

Maskable interrupts now respect the guest's COP0 interrupt enables and
exception state. Automatic thread preemption also defers across masked
sections. A regression using the original queue submission reproduces incorrect
interrupt timing in the preceding scheduler and verifies deferred delivery and
released ownership after this change. The retail post-save freeze remains
unverified; this test establishes the scheduler correction.

Sprite workers now support indexed and 16/24-bit textures, independent depth
buffers, additional framebuffer formats, unaligned bases, and region wrapping.
Feedback, stale sampled pages, and color/depth dependencies retain serial
ordering. Constant-alpha passes that preserve destination RGB avoid unused
texture samples even when drawing serially. Full VRAM comparisons cover 58
fixtures, including colored palettes and dependent cache reads.

Isolated 512x448 tests of newly supported draws measured roughly 14–17 ms in
the previous renderer and 3–5 ms in this renderer, with identical complete VRAM
hashes. These are component timings, not retail FPS. Stable 60 FPS and gameplay
remain unverified.

Bounded sprite profiles record worker eligibility and depth/texture formats.
Stall reports include copied DMA registers, tags, queued commands, and interrupt
state. The original USA ISO remains required at every launch. Existing saves
remain in the disc cache's `mc0` directory.
