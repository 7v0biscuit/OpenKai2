# v0.1.89

Faster internal resolution, upscalers that work with it, and lighter HD textures.

- Internal resolution (2x, 3x, 4x): the graphics card now shrinks the picture
  to the window height and converts it before it is copied out, instead of the
  processor rebuilding the full picture every frame. At 4x in a 1080p window
  the copy per frame drops from about 18 MB to about 7 MB, and the picture
  gets smoother edges.
- Upscalers: when the picture is larger than the window, every upscaler except
  Nearest now averages it down. Before, AMD FSR 1 fell back to nearest pixels
  and the others skipped pixels, which caused shimmering.
- HD textures: textures the game uploads again unchanged are recognised
  without reading them again, and at most 262,144 new texels are read per
  frame, so new textures cannot stall a frame. Texture packs with no PNG files
  turn themselves off.
- HD textures need internal resolution 2x or higher. Choosing an HD texture
  mode now sets 2x when it was Native, and saved settings with HD textures at
  Native load as 2x.

If a fight still drops below 60 FPS at 2x, 3x or 4x, please attach
`startup.log` from that fight.

Download **OpenKai2.exe** for the portable app, **OpenKai2-windows-x64.zip** to
extract manually, or **OpenKai2-Setup.exe** to install. The original Budokai 2
USA ISO is required at every launch. Checksums are in **SHA256SUMS.txt**.
