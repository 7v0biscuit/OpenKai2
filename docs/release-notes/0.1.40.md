# v0.1.40

Disc reports go one step further into Budokai 3's character table.

The Budokai 2 and Budokai 3 reports showed:
- Both games pack their data in the same containers (`#AMB`, `#AMT`, `#AMK`,
  `#SPX`, `#AMA`, `#AMM`), at the same container version. Budokai 3 also has
  `#BPL`, `#LST` and `#AMO` files, which Budokai 2 does not.
- Each Budokai 2 character has one model per costume (about 800 KB each),
  then three more files. Budokai 3's characters are laid out the same way,
  with their costume models in the same kind of container at similar sizes.
  Budokai 3 packs its other files differently.
- Budokai 3's character records are 96 bytes each. Each points at its name
  and at two smaller blocks of data, which probably say which files belong to
  the character.

The report now also shows:
- every file inside each `#AMB` container, with its first bytes, so the model
  formats of the two games can be compared;
- every string in the character name lists, including names the report did
  not recognise before;
- all the records of tables that point at names, including records without a
  name, one per line;
- the data those records point at.

To continue mapping Budokai 3, save the Budokai 3 and Budokai 2 reports again
with this version and send both. Characters cannot be imported from Budokai 3
yet.

Not fixed yet: in Dragon World the character can walk off screen, and the
dialogue text and the Yes/No prompt after character select are invisible.

The original USA ISO is required.
