Preview 34 gets past the earlier graphics queue wait and reads the existing
save successfully. The new retail log stops at an untranslated depth initializer,
`0x001A9380`, called indirectly by the scene packet builder at `0x0013A20C`.

This release exposes that callback's original instructions and checks all eight
related render setup entries. The native regression verifies packet fields,
shared float values, return delay slots, saved registers, memory guards, direct
RAM, and the logged uncached RAM alias. It also runs the original selector
and actual packet-builder indirect call together. No callback is replaced by
a no-op and no save confirmation is bypassed.

The latest log records 9,351 completed parallel draws. The movie decoder returns
about 17.5 pictures per second in that session; that counter does not establish
displayed FPS. This release addresses the newly identified callback stop and
makes no additional renderer performance claim. Full gameplay, progress beyond
this initialization callback, and stable 60 FPS remain unverified.

The original USA ISO remains required at every launch. Existing memory-card
files remain in the disc cache's `mc0` directory.
