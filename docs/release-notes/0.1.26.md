# v0.1.26

Fix launcher dropdowns and add AMD FSR 1 spatial upscaling.

- Allocate native popup space so every settings list opens correctly.
- Preserve focus while choosing values, save preferences automatically and
  restore them when reopening the launcher.
- Group display and rendering options in a simpler layout with a graphics-only
  reset. Keep automatic save backups on the Saves page.
- Run update checks independently of ISO selection and settings. Queue update
  installation until the game and save operations finish.
- Record selected display preferences and the applied window state in logs.
- Add AMD's EASU upscaling and RCAS sharpening as **AMD FSR 1 · Spatial**.
  Keep filtering inside active content and preserve image orientation and bars.
- Check actual native popup behavior with mouse and keyboard interaction,
  persisted values, reopening, reset and minimum-size layout.

FSR 1 processes the completed image; it does not accelerate guest execution.
FSR 3/4 temporal reconstruction and frame generation remain unavailable because
the renderer lacks their required inputs and backend. Host audio remains off.
The original USA ISO is required. Complete story progression, correct character
poses, stable 60 FPS and complete matches remain under development.
