# v0.4.5

More room for mods, Budokai 3 voices, and playable stage imports.

- **24 added characters instead of 14.** Character IDs 53 to 62 now work, so
  mods can fill 24 unused IDs. Added characters also show their portrait in the
  fight HUD, which was blank before.
- **Imported Budokai 3 characters bring their own fight voice.** Importing a
  whole Budokai 3 model as a new character now copies that character's voice
  from your Budokai 3 disc. Works for the 44 regular Budokai 3 characters;
  fusions keep their base character's voice. Re-import a character to get it.
- **How to play an imported stage is now explained.** An imported stage takes
  the place of ISLAND B, TOWN B, R&R BASE B or SNOW B. Pick ISLAND, TOWN,
  R&R BASE or SNOW on the stage select screen and confirm with Circle (C on the
  keyboard) instead of Cross. The import tool now says this.
- **Backing out of stage select keeps your added character.** The character
  select screen no longer jumps to Random after you picked a character on an
  added spot.

Known issue: added spots on the character select screen still show the name
"Random" and borrow another spot's portrait.

Both players need v0.4.5 to play together online.

Download **OpenKai2.exe** for the portable app, **OpenKai2-windows-x64.zip** to
extract manually, or **OpenKai2-Setup.exe** to install. The original Budokai 2
USA ISO is required at every launch. Checksums are in **SHA256SUMS.txt**.
