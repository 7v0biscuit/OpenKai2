# v0.1.19

Reduce vector arithmetic overhead, preserve triangle depth precision, and
register the remaining actor timing callbacks.

- Classify only operands read by each vector instruction when unrelated
  register data prevents the existing bounded-input check from succeeding.
  Respect destination masks, broadcast lanes, Q/I operands, accumulator use,
  and cross-product lane selection. Retain the original exceptional-input and
  cancellation calculations, results, flags, and guest cycle boundaries.
- Interpolate triangle depth from vertex differences on CPU and GPU. Preserve
  exact constant integer depth, including the full 32-bit maximum, and prevent
  nearby surfaces from acquiring spurious depth variations.
- Register ten methods and two continuations in the actor timing bank,
  including the frame-delta callback at `0x001FC1E0`. Verify the original bank,
  catalog, complete instructions, and generated dispatch entries. Add 174
  native cases for copied data, timer boundaries, and original caller dispatch.
- Compare 128 additional vector states with the pinned original interpreter.
  Check ten exact constant-depth cases and eight overlapping depth planes
  against independent equations on both rendering paths. Retain the existing
  arithmetic, scheduling, packet, material, sampler, and full-VRAM references.

Three alternating Windows-binary runs under Wine measured about 32% lower
median CPU cost across the 32 targeted vector programs; individual reductions
were 5–50%. The two clean control groups had median costs about 0.2% and 2.4%
higher. All output state and cycle hashes matched the previous runtime. These
synthetic costs do not establish retail game FPS.

The original USA ISO remains required at launch. Host audio remains disabled.
Character poses, complete matches, and sustained 60 FPS remain unverified.
