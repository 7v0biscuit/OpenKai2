# v0.3.4

Rollback netcode for online matches.

- Online matches no longer wait for the other player's buttons. Input delay is
  at most 2 frames; when the other player's buttons for a frame are late, the
  game repeats their last buttons and keeps running. If the real buttons were
  different, it returns to the last correct frame and replays to the present
  in an instant, without drawing or sound.
- The game runs up to 8 frames ahead of the other player before it waits.
  During loading screens and other moments the game cannot save, it waits for
  the real buttons as before.
- The out-of-sync check only compares frames whose buttons both players have
  confirmed.
- **Music off** no longer breaks online matches. It changed the music data the
  game reads, so a player with music off and one with music on went out of
  sync as soon as music played. Music off is now ignored online.
- Fixed a rare crash when a match was closed while the host was still
  accepting the other player.

Set `OPENKAI2_NETPLAY_ROLLBACK=0` on both PCs to go back to lockstep. Both
players need v0.3.4 to play together.

Download **OpenKai2.exe** for the portable app, **OpenKai2-windows-x64.zip** to
extract manually, or **OpenKai2-Setup.exe** to install. The original Budokai 2
USA ISO is required at every launch. Checksums are in **SHA256SUMS.txt**.
