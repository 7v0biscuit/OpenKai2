# v0.1.81

Launcher layout and navigation cleanup, with the game fixes from v0.1.80.

## Launcher

- Keep settings controls and the Release notes button above the status footer
  in shorter windows. Larger windows retain their existing spacing.
- Correct the keyboard hint: V is Triangle/back. C is Circle.
- Rename the save selection action to Deselect all, distinguishing it from deletion.
- Use consistent import labels and describe internal resolution relative to the
  game's native size instead of assuming every scene uses the same dimensions.
- Keep section descriptions clear of their action buttons.

## Releases

- Retry temporary GitHub server errors during release cleanup.
- Remove older development releases, tags and release inputs after publication.
  Preserve unmerged branches and future release inputs; merged branch deletion
  checks that its commit has not changed.

Includes the Dragon World post-battle and Skill List exit freeze fixes from
[v0.1.80](https://github.com/7v0biscuit/OpenKai2/blob/main/docs/release-notes/0.1.80.md). Full Dragon World completion remains unverified.
