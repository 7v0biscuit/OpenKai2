# v0.1.68

Unique online names and a fixed developer tag.

## Online

- Profile names are unique across OpenKai2. Adding a profile checks the online
  service, and a name another profile already holds is refused. Case, spaces
  and symbols do not count, so "Joint" and "joint" are the same name.
- A profile whose name is held by someone else shows **Name taken** and stays
  hidden from other players.
- Players whose name does not match its holder are marked "(name not
  verified)" in the Players list, invites and friend requests.
- `OpenKai2Lobby` refuses copied names outright.
- The **[DEV]** tag works again for the developer, whose profile is
  **[DEV] Biscuit**. It still needs the developer key, which is not included in
  OpenKai2.

The original USA ISO is required.
