# Vector pipeline scheduling

This release reduces the cost of vector execution used by menus, character
rendering, and combat.

- Replace full pipeline scans and free-slot searches with active-slot masks.
  Preserve original slot order, write suppression, flags, and result latency.
- Advance through idle cycles to the next pending result. Keep PATH1 stores,
  qword reads, and graphics callbacks on their original cycle boundaries.
- Compile vector handlers together so operand normalization and pipeline
  helpers can be inlined across instruction handlers.
- Compare 128 additional original interpreter references across VU0/VU1,
  eight resume budgets, resets, register and flag state, memory, and packet
  callback cycles. The component suite includes 42 cases.
- Measure `path1-submit` separately within vector execution so logs distinguish
  graphics submission from interpreter cost. Nested timings are inclusive.

Three alternating native Linux synthetic runs against the preceding release
reduced arithmetic workload time by 42%, integer work by 62%, and a 4 KiB packet
workload by 81%. All sixteen workloads retain matching guest cycles and output
hashes. These kernel measurements do not establish retail gameplay FPS.

Host audio remains disabled. The original USA ISO is required at every launch.
Complete matches and sustained 60 FPS remain unverified.
