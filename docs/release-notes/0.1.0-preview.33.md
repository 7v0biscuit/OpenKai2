Large independent CT32 sprites now draw across up to four persistent CPU
workers. Each worker owns its sampler cache. Stale sampled pages, framebuffer
feedback, depth dependencies, and unsupported formats retain serial execution.
Eligible passes that preserve destination RGB can avoid unused texture samples
while retaining alpha writes, tests, masks, and final sampler state.

Paired 512x448 draw tests measured about 13.30 to 3.96 ms for filtered opaque
sprites, 17.47 to 5.31 ms for blended sprites, and 17.96 to 1.25 ms for eligible
alpha-only passes. These are isolated wall-time measurements, not game FPS.
Complete VRAM comparisons cover 24 serial/parallel fixtures, stale caches,
dependent draws, and fallbacks. Worker errors wait for every partition before
propagating, and the pool remains usable afterward.

The original save-menu callbacks are now tested from completed card detection
through directory search and creation, including the original frame poller and
repeated stability checks. The retail save freeze has not been reproduced or
verified fixed. Preview 32's latest log ends during a card check, despite the
user closing the window normally.
An additional scheduled test injects an interrupt at each of 21 real SDK
completions and verifies card stability and the caller's stack afterward.

New bounded stall reports record the guest program counter, stack, save-menu
callback, fade state, card command, and DMA queues after five seconds without
game-side input reads. RAM is copied on the EE executor; the window thread
only prints that copy. Shutdown records are written before waiting for the
game thread. These observations do not bypass guest waits or confirmation.

The original USA ISO remains required at every launch. Stable 60 game FPS and
gameplay remain unverified. Save files stay in the disc cache's `mc0` directory.
