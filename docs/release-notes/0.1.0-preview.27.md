This preview connects the game's IPU DMA input to the software MPEG decoder.
The Preview 26 log gets past timing conversion but leaves the movie worker
waiting inside picture decoding, with compressed video still buffered.

DMA channel 5 now transports its source bytes and completes its registers and
status. Source chains are bounded and checked before input is committed. The
runtime preserves a completed chain across CRI pause/resume and clears the IPU
reset command on readback.

Picture decoding uses the original SDK work layout and success result, preserves
its decode-mode and picture-info fields, and invokes the original SDK/CRI refill
path when more input is needed. Decoded pixels retain the existing presentation
timing and GS pixel layout. Screen-presentation code is unchanged.

The previous runtime reproduces the MPEG wait using a generated stream. The new
regression encodes three patterned MPEG-2 pictures, sends them through the
original CRI ring and DMA routines, and checks their decoded pixels, dimensions,
frame indices, SDK results, pause/resume, refill callbacks, and memory bounds.
Component checks cover reset, normal input, malformed chains, invalid ranges,
and unsupported transfer modes. Windows publication requires the decoding test
in the installed application.

These tests use generated input. Full retail movie playback, audio synchronization,
title-screen boot, and gameplay remain unverified. The original USA ISO remains
required at every launch.
