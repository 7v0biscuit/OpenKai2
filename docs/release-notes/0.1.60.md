# v0.1.60

Fixes a freeze with stages imported from Budokai 3 in v0.1.59.

Your log shows the game jumping to address 0 from Budokai 2's pack loader
(`[guest-branch:missing-target] ... source=0x12a75c target=0x0`). That loader
handles seven kinds of file in a stage's `#AMB` pack (`#AMG`, `#AMT`,
`#AMM`, `#AMO`, `#AMC`, `#AML` and `#AMP`), looked up in a table at
`0x33D680`. For any other kind it calls nothing and the game stops. The
imported Town B stage's pack holds a kind Budokai 3 added.

- **At start-up**, a stage mod whose pack holds a file Budokai 2 can't load is
  now skipped, with a `[mods] stage: skipped ...` line in the startup log.
  Your Town B mod no longer freezes the game; Town B stays as it was.
- **In the import tool**, Budokai 3 stages using such files are marked
  "can't be imported", and the sentence beside Import says which kind of file
  is the problem.
- **The disc report** lists the file kinds in each Budokai 3 stage's pack.
  Please save one from your Budokai 3 disc and send it, so the unknown kind
  can be looked at for converting.

If the game still freezes in the same place, the stage was not the cause:
please send the new startup.log and say where it froze.

Not fixed yet: in Dragon World the character can walk off screen, and the
dialogue text and the Yes/No prompt after character select are invisible.

The original USA ISO is required.
