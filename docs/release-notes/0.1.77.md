# v0.1.77

Higher internal resolution, HD textures and a Dragon World permadeath fix.

## Graphics

- **Internal resolution** in Settings renders 3D scenes at 2x, 3x or 4x
  (up to 2560x1792) with the GPU and Vulkan renderers. It needs more graphics
  power and applies the next time the game starts. Videos and effects that the
  game builds from its own picture stay at native resolution.
- **HD textures** in Settings (needs 2x or higher):
  - *Upscaled from your disc* smooths the game's own textures while you play.
    Nothing is downloaded.
  - *Texture packs* load PNG files from the textures folder. Each file is named
    by the texture's hash, so packs work with any copy of the game.
  - *Texture packs, upscale the rest* uses a pack where one exists and upscales
    everything else.
  - *Dump textures for pack makers* saves each texture the game uses once to
    `textures\dump`. Edit a copy at any size and put it in the textures folder.
  - **Open texture folder** opens the folder.
- `startup.log` reports how many frames were shown at the higher resolution and
  how many textures were upscaled or loaded from packs.

## Speedrun mode

- Permadeath now ends a Dragon World run when your fighter is knocked out.
  Some losses were read as wins, so the run carried on. The game over screen
  stays up a little longer before returning to the main menu.
- A fight lost on time counts as a loss; a fight ended by a story scene does
  not.
- Wins in Dragon World are read from the fighters' health, so splits are no
  longer added for lost fights.

The original USA ISO is required.
