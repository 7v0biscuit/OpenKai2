Fixes pending IOP loads at imported function calls. Arguments loaded in a call's
delay slot are now visible before thread creation, thread startup, or RPC
registration. A pending load also cannot overwrite an imported return value.

The regression executes synthetic MIPS modules through the IOP emulator. It
starts a thread, registers an RPC handler, and verifies the handler's reply.
The installed application's `--self-test` includes these checks.

Startup logs also retain bounded thread creation, start, exit, and sleep events
to help trace CRI initialization if its RPC server remains unavailable.

The original Budokai 2 USA ISO is required at every launch. Title-screen boot
and gameplay remain unverified; the new log identified the area under
investigation, while the pipeline bug was reproduced with a separate guest
module.
