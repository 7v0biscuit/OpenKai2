# v0.1.100

Hand-printed theme pictures and a tidier launcher.

- Theme pictures: all five themes (Dragon Balls, Capsule, Dragon Radar, Ki and
  Scouter) have new pictures drawn in a screen-print style, with spot inks,
  rough hand-drawn lines, dot shading and handwritten notes.
- Themes: only the five picture themes remain. Dragon Balls is the default. If
  you used an older theme, the launcher moves you to the closest one.
- Accent colors: the list is down to Orange, Gold, Red, Pink, Purple, Blue,
  Cyan, Green and White, plus the theme's own color and **RGB (cycling)**.
  Colors that looked almost the same are gone; if you used one, the launcher
  moves you to the closest remaining color.
- README and known issues updated to match the current build.

Download **OpenKai2.exe** for the portable app, **OpenKai2-windows-x64.zip** to
extract manually, or **OpenKai2-Setup.exe** to install. The original Budokai 2
USA ISO is required at every launch. Checksums are in **SHA256SUMS.txt**.
