# Attack effects and pixel throughput

This release registers missing attack-effect constructors and callbacks,
extends the prepared CT32 renderer, and disables host audio playback.

- Register 16 attack-effect methods, including the indirect target at
  `0x209560`. Check 114 constructor cases through the original call site,
  including allocation failure, three resource types, node links, callbacks,
  input packets, and preserved registers.
- Prepare alpha-test outcomes, destination-alpha tests, framebuffer masks,
  and FBA for CT32 drawing. Compare 147,456 sprite and triangle cases with the
  unchanged scalar point pipeline and retain all existing VRAM regressions.
  Inline CT32/Z32 address lookups also remove indirect per-pixel memory calls.
- Disable audio device startup, decoded-sound playback, PCM queue delivery,
  and audio mixing callbacks. Guest sound RPC and DMA timing remain enabled.
  Audio remains disabled while performance work continues.

A 32-case Windows binary benchmark under Wine measured about 8–23% lower
serial draw times for the newly optimized states. Four-worker results varied
from 2–28%. All reference VRAM checksums matched. These synthetic measurements
do not establish retail game FPS.

The original USA ISO is required at every launch. Complete retail matches and
sustained 60 FPS remain unverified. Graphics still use the CPU renderer.
