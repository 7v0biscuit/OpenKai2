# v0.2.4

A new launcher layout and custom speedrun split appearances.

- Bottom navigation keeps all eight pages together. Tabs can be reordered freely
  or hidden, with matching Ctrl+1 to Ctrl+8 shortcuts and hover hints.
- Inter and Barlow Condensed improve text clarity. Panels, settings labels and
  quick-access actions have consistent spacing. Settings stays in the dock.
- Smaller windows scroll within the page while the header and dock stay in
  place. Clipped controls and stale text after scrolling have been corrected.
- Dropdowns save confirmed choices. Escape restores the previous choice, and
  background online refreshes leave an open dropdown alone.
- Ctrl+O chooses an ISO, F5 starts the verified game, Ctrl+L opens logs, and
  Alt+Left or Escape returns from a detail page.
- Profiles have local initials, an accent and a tagline, plus a public-ID copy
  button. Each profile keeps its own appearance.
- The speedrun overlay checklist is replaced by a split editor. Rename each
  split and attach your own PNG, JPEG or GIF from disk or by drag and drop.
  GIF timing, transparency and animation are supported. There is no bundled
  split artwork.
- Split appearances are separate for each category and difficulty. They do not
  change recorded times. PS2 time and verification labels remain fixed.
- Overlay images are decoded before gameplay. Animated textures update when
  their frame changes; long names and large layouts stay within the game window.
- Windows source builds use portable HD texture page hashing, fixing an MSVC
  compile error. Both Windows build paths include the split image checks.

Gameplay has been verified through completion in playtesting. Music playback
and mod tools remain under development; see [known issues](../known-issues.md).
