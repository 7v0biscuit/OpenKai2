# v0.1.46

Fix the zoomed-in select-screen preview of imported characters for good.

v0.1.45 pointed one of the preview's three readers of the camera table at the
base character's row, but two more read it with the character's own ID, so
characters such as an imported Frieza still looked zoomed in. All three now
use the base character's row, and the byte the preview reads per character
too. Characters imported with earlier versions get the fix without importing
again.

Budokai 3 models drawn black: the v0.1.45 reports show that Budokai 3's
Krillin model is almost the same as Budokai 2's. Its textures, palettes and
mesh blocks match nearly word for word, and the texture data is in the same
form. So the import itself is most likely fine, and the black probably comes
from the character ID the model is put in, which the game may not set up for
textures. A test in game will tell: see below.

To help find the black models, please try:
1. Import a Budokai 2 character from your Budokai 2 disc (for example
   Krillin, sharing his spot), and see whether it is black too.
2. Note the character ID the import tool names when it finishes.

Not fixed yet: in Dragon World the character can walk off screen, and the
dialogue text and the Yes/No prompt after character select are invisible.

The original USA ISO is required.
