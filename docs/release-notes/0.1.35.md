# v0.1.35

Mods, a Mods page in the launcher and an import tool for characters,
movesets and stages.

- Load mods through a virtual disc over the ISO. The game sees modded files
  at their usual paths; the ISO is never changed, and disabling a mod brings
  back the original disc. Mods can replace whole files, replace AFS archive
  entries, or add any number of new entries.
- Add a **Mods** page (Ctrl+3; Settings moves to Ctrl+4). It lists mods in
  load order. You can enable, disable, reorder and create mods there, and
  open the mods folder at `%LOCALAPPDATA%\OpenKai2\mods`.
- Add an import tool. It reads any PS2 ISO, such as Budokai 2 or Budokai 3,
  and lists its files and archive entries. It copies chosen entries into a
  mod as new entries, replacement entries or a whole-file replacement. It
  also imports files from disk, for content made from scratch, and extracts
  entries to files for editing.
- Document the mod folder format in `docs/modding.md`.

Limits: data from Budokai 3 is copied as is and may not work in Budokai 2.
Added entries are stored on the disc, but they do not appear as new
select-screen slots until the game's character and stage tables are mapped.
Replacing existing characters and stages works now.

Not fixed yet: in Dragon World the character can walk off screen, and the
dialogue text and the Yes/No prompt after character select are invisible.

The original USA ISO is required. The mod system is verified by unit tests
and launcher interaction tests. Mods need in-game confirmation.
