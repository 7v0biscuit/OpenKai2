This preview exposes the missing SJRBF stream callbacks in the native translation.
The latest retail log confirms that the four EE workers now start, then shows
the main thread stopping at an indirect call to `0x0016D310` from `0x00156FE8`.

The stripped-ELF analysis had merged the cleanup method and two adjacent methods
into a larger function without callable entries. Translation hints now cover all
nine methods in the original stream table while preserving its three reserved
null slots. The generated dispatch table must expose each method at its own
instruction, and the input executable and table contents are verified.

The executable's self-test runs the original cleanup caller with the logged
object layout and checks object release, neighboring memory, and the caller's
saved registers. It also executes stream construction, interface queries, reset,
chunk acquisition and recycling, rollback, ring wraparound, and error callbacks.
Release publication requires that regression to pass in the installed Windows
application.

The original USA ISO is required at every launch. Title-screen boot and gameplay
remain unverified. Retain `startup.log` when testing this development preview.
