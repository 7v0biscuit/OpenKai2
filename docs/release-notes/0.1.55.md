# v0.1.55

A second fix for the black and blue Budokai 3 bodies, found with the v0.1.54
mesh comparison.

Compared word by word, Supreme Kai's mesh differs between the games in only
two ways besides vertex data and texture numbers (which follow each game's
own texture order):

- every material record: Budokai 2 sets bit `0x2000` (`0x21B5`), Budokai 3
  leaves it clear (`0x01B5`). v0.1.52 already sets it.
- 27 draw records in the mesh's first block: Budokai 2 sets bit `0x20`
  (`9000022C`, `8000022C`, `6000022F`, `00000224`), Budokai 3 leaves it clear
  (`9000020C`, `8000020C`, `6000020F`, `00000204`).

Forced imports, and the **A** version of **Compare 4 versions**, now set both.

- Characters forced in with earlier versions keep the old mesh; delete their
  mod and force them in again.
- Checked by unit tests against the pattern in your reports, not yet in game.
  Please say whether the colours show now.
- The disc report counts each model's draw records and how many carry the
  flag, to check the pattern finds the same 27 records in Supreme Kai and
  holds for other characters.

Not fixed yet: in Dragon World the character can walk off screen, and the
dialogue text and the Yes/No prompt after character select are invisible.

The original USA ISO is required.
