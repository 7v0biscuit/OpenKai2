# v0.1.36

Characters by name in the import tool, new characters on the select screen,
and an import tool that no longer freezes.

- Map the game's character tables: 53 character records, each listing the
  character's files in `DATA_CMN.AFS`, and the select grid. Fourteen IDs have
  names but no data. A mod's `roster.ini` can fill one of them from a base
  character, point its files at entries the mod adds, and put it in a select
  cell. See `docs/modding.md`.
- List characters by name when the import tool reads a Budokai 2 USA disc.
  Choosing a character selects all of its files together.
  - **Add as new character** copies them as new entries, fills an unused
    character ID and places it in the select cell you choose.
  - **Replace a character** writes them over another character's, file for
    file.
- Read discs, import and extract in the background, with a progress bar and
  percentage. These used to run on the launcher window's thread and held whole
  files in memory, so large archives froze the launcher. Imports now stream
  through temporary files, and failures of any kind are reported instead of
  closing the launcher.

Limits:
- The select screen still has 29 cells, so a new character takes over a cell
  from the character shown there.
- Data the character record does not name, such as voices, story scenes and
  skill capsules, stays the base character's.
- Stages and capsules are not listed by name yet.
- Budokai 3 discs open in the file view, because their tables are not mapped.

Not fixed yet: in Dragon World the character can walk off screen, and the
dialogue text and the Yes/No prompt after character select are invisible.

The original USA ISO is required. The roster and import changes are verified
by unit tests and by the import tool against the USA executable's tables.
They need in-game confirmation.
