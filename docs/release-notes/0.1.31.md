# v0.1.31

Synthesize sound effects and reverb, stop audio pops, remove a per-frame GPU stall and default to a 240 FPS cap.

- Synthesize game audio with PCSX2's SPU2 core. It mirrors every SPU2
  register write and transfer the emulated IOP makes, so sound effects,
  per-voice volumes and reverb play alongside music and voices. The game
  still sees the existing SPU2 emulation, so its timing is unchanged.
- Time-stretch audio when the game runs below full speed. Before, the stream
  ran dry and gapped, which was audible as pops; it now slows without
  changing pitch.
- Stop waiting for an idle GPU on every GS `FINISH` write. Host reads of VRAM
  already wait for the pages they need, so the game thread no longer stalls
  on the GPU each time a display list ends.
- Flush pending draws before a texture upload only when they sample the
  uploaded pages.
- Forced bilinear filtering now smooths 3D surfaces only. Sprites (HUD,
  text, portraits and effect atlases) keep the game's filtering, so
  neighbouring images no longer bleed into each other.
- Default the frame rate cap to 240 FPS. The game itself draws at most 60
  frames per second; a higher cap lowers presentation latency.
- New `gpu-wait` and `gif-path23` timers in the startup log break down GPU
  synchronization and GIF path 2/3 time.

The original USA ISO is required. Audio and frame-rate changes are covered
by unit tests and need in-game confirmation.
