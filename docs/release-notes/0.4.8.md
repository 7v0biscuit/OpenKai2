# v0.4.8

Higher frame rates, especially at high internal resolutions.

- **The game no longer waits for drawing to finish before every frame.** Until
  now, the game stopped at the start of each frame until all drawing for the
  previous one was done. It can now start the next frame while the last one is
  still being drawn, so the two overlap instead of adding up. The frame on
  screen still comes from the right point in time.
- **Vulkan no longer stalls while showing a frame.** Copying the finished frame
  to the window used to block the graphics card's work queue each frame (about
  4 ms at 4x). The copy now runs on its own track, and more work can be queued
  for the graphics card at once.
- **Fewer small waits while drawing.** Screen clears and end-of-drawing signals
  are queued with the rest of the drawing work instead of forcing a wait.

If drawing looks wrong, setting the environment variable
`OPENKAI2_SYNC_RASTER=1` turns off the separate drawing thread. Either way,
please send your startup log.

Known issue: added spots on the character select screen still show the name
"Random" and borrow another spot's portrait.

Both players need v0.4.8 to play together online.

Download **OpenKai2.exe** for the portable app, **OpenKai2-windows-x64.zip** to
extract manually, or **OpenKai2-Setup.exe** to install. The original Budokai 2
USA ISO is required at every launch. Checksums are in **SHA256SUMS.txt**.
