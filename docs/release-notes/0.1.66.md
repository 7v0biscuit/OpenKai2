# v0.1.66

Online play with a server browser, save states, no more audio pops, and
permadeath that ends the run on any loss.

## Online play

- New **Online** page in the launcher. Host a room or join one over the
  internet. The host is player 1 and the joining player is player 2.
- **Profiles:** add one or more profiles; the selected profile's name is shown
  to the other player. A profile is needed to play online.
- **Server browser:** list your room on a lobby server, with an optional room
  name and password, or browse open rooms and join with one click. Locked rooms
  ask for the password. You can also join by address.
- The host sends its memory card and game state to the joining player, so both
  games start the same. The games then exchange button presses a few frames
  ahead (input delay, 1 to 8 frames, set by the host) and run in lockstep.
  Every two seconds they compare memory; a mismatch shows "out of sync".
- An in-game bar shows the opponent, ping and input delay.
- Both players need the same OpenKai2 version and disc. Mods, save states and
  speedrun mode are off online. Your own memory card is not changed.
- `OpenKai2Lobby` is a small lobby server for the server browser that anyone can
  run (see `docs/online.md`).
- The PS2 clock now counts console time from a start time kept in the game
  state, instead of reading the PC clock at every call, so both games see the
  same time.

## Save states

- **F5** saves and **F9** loads (slot 1). States hold the whole console: CPUs,
  graphics memory, vector units, sound, timers and the kernel state.
- States are taken between frames. A state from another build or disc is
  refused, and a failed load puts the game back where it was.
- Not available while a movie plays or in speedrun mode.

## Audio, speedrun, display

- Music and movie audio no longer pop or buzz. Stream transfers now finish when
  the sound chip asks for more, as on a PS2. In a 60-second test this cut
  replayed blocks from about 250 to none outside start-up.
- Permadeath: losing any Dragon World fight, with Goku or a partner, ends the
  run. The attempt is saved and the game resets to the main menu with the timer
  reset.
- The FPS counter is larger, on a dark backing.
- Settings: Speedrun now sits above Updates, which is last.
- The GPU renderer logs why it waits for the GPU
  (`[renderer:wait] reason=present|palette|transfer|upload|vram|snapshot`) when
  the game closes.

The original USA ISO is required.
