# v0.1.66

No more audio pops, permadeath that ends the run on any loss, and GPU wait logging.

- Music and movie audio no longer pop or buzz. The game streams them into the
  sound chip in half-buffers. The emulated I/O processor timed each transfer
  on its own clock, while the sound chip read its buffer on another, so the
  two drifted and the sound chip sometimes played a half twice. Transfers now
  finish when the sound chip asks for more, as on a PS2, and the sound chip
  keeps time with the I/O processor in 1 ms steps while a stream is playing.
  In a 60-second test this cut replayed blocks from about 250 to none outside
  start-up.
- Permadeath: losing any Dragon World fight, with Goku or a partner, ends the
  run. "Run over" shows, the attempt is saved, and the game resets and goes
  back to the main menu by itself, with the timer reset.
- The FPS counter is larger, on a dark backing, in the top corner.
- The GPU renderer logs why it waits for the GPU
  (`[renderer:wait] reason=present|palette|transfer|upload|vram|snapshot`),
  with counts and total time, when the game closes. This shows which waits
  slow fights down.

The original USA ISO is required.
