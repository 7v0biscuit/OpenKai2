Fix graphics DMA completion when a valid transfer has no payload. The previous
runtime could leave the game's DMA queue active indefinitely, causing its
VBlank callback to keep deferring game updates and controller reads.

The regression uses two original translated queue submissions, both completion
handlers, and the original VBlank callback. It reproduces the blocked frame
before the fix and verifies queue retirement and frame release afterward.
Device checks cover VIF0, VIF1, GIF, normal transfers, empty END/REFE tags,
IRQ termination, nonempty payloads, and invalid chains. Polling an invalid
graphics chain no longer clears its busy bit.

New bounded frame-wait records expose guest flags and DMA queue state when
investigating the save confirmation. Preview 31's retail log confirms responsive
host input, followed by stopped game reads and drawing after card detection;
it does not identify the precise pending transfer. This release fixes the
reproduced completion defect, but the retail save confirmation and gameplay
remain unverified. Stable 60 game FPS has not been achieved or verified.

The original USA ISO is required on every launch. Save files remain in the
disc cache's `mc0` directory.
