Preview 25 log. The parser now supplies video and audio buffers, then the movie
worker exits at an unregistered indirect call to 0x0019D4F0. The user confirms
that screen shaking is fixed; the field-presentation code is unchanged.

All seven handlers in the original time-code table are now reviewed translation
entries. Validation checks all nine rates, both modes, reserved and repeated
slots, and each handler's exact entry point. There are 163 reviewed entries.

The regression reproduces the logged missing target on the previous translation
and runs the original dispatcher through 126 combinations of rates, modes, and
time codes. It checks conversion outputs, second/minute/ten-minute/hour boundaries,
long-duration wrapping, caller frames, saved registers, input preservation, and
memory guards. Windows publication requires this regression in the installed
application's self-test.

These checks use synthetic time codes. Actual movie decoding, visible playback,
title-screen boot, and gameplay remain unverified. The original USA game ISO is
required at every launch.
