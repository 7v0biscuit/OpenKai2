This preview corrects the horizontal split, stretching, and flashing caused by
reading beyond the game's interlaced display buffer.

The game stores a 512x224 display next to its larger render target and presents
it as 512x448 in interlaced FRAME mode. The renderer previously read 448 memory
rows, mixing those two buffers. It now reads 224 rows and expands them to the
output height before merging the display circuits. Black fades also retain
the actual display buffer rather than exposing an older render target.

A patterned regression checks every displayed pixel, consecutive fields, both
read circuits, nonzero framebuffer origins, black fades, progressive output,
and full-height field parity. The Windows installer publication gate requires
this check in the installed application's self-test.

The latest retail log confirms that the opening movie is found but remains in
preparation without an SDK error. New bounded snapshots identify the native
preparation parameters, driver status and callback tables, and video input
state. The movie stall is still unresolved; movie playback, title-screen boot,
and gameplay are unverified. The original USA ISO is required at every launch.
