This preview addresses the sound RPC startup race shown in the latest log.
The previous disc-search fix succeeds, and startup now loads the remaining sound
modules. The first bind to SID `0x11` happens while a module worker is still
queued, sending the game into its sound-bind error loop at `0x00146838`.

Resident module loading now runs ready IOP workers before returning to the EE.
Workers must register their actual RPC handlers; missing servers remain absent.
The handoff stops when workers block, preserves future wake deadlines, and uses
a bounded execution budget so a busy worker cannot hang module loading.

Regression checks reproduce the earlier first-bind failure and verify nested
worker registration, interpreted RPC execution, sleep, delayed startup, reset,
and busy-worker limits. The installed executable runs this regression through
`--self-test`, and release publication requires it to pass on Windows.

Title-screen boot and gameplay remain unverified. Run this development preview
with the original USA ISO and retain the startup log.
