# v0.3.2

A clearer launcher, safer profiles and smoother navigation.

- Fixed controls shifting after a scrollbar appeared or disappeared when
  resizing. Returning from another application, minimizing, changing display
  scale and closing a file picker now rebuild the launcher’s painted controls.
  Unconfirmed dropdown choices and key captures are cancelled on focus loss.
- Refreshed the Play dashboard, player cards, page headings and six-tab dock.
  Compact windows reorganize the dashboard and scroll tools above the dock.
  Controls and Saves & backups remain on Play; patch notes stay visible there.
- Settings have section filters, token-based search, consistent field spacing
  and dropdown menus that expand to show long choices. Ctrl+F focuses the
  current page’s search. Ctrl+K finds pages, tools and settings sections.
  Duplicate selection notifications keep the last useful Undo change.
- Profile customization includes quick switching, picture framing, appearance
  copying, online availability and per-profile quiet notifications. Removal
  asks first and creates a recovery copy; Undo removal restores the identity,
  friends and appearance without replacing game preferences.
- Friend requests and match invitations have a Notifications inbox, opened
  with the bell or Ctrl+Shift+N. Quiet profiles keep requests in the inbox.
- Added reduced motion and optional hover hints. Animation pauses while the
  launcher is inactive. The saved Discord activity preference is respected.

Profile pictures, initials, taglines and colors stay on this PC. Online
availability is shared with other players. Both players need the same OpenKai2
version for online matches. The v0.3.1 game, save-state and rollback groundwork is retained.
Music playback and mod tools remain in development.

Download **OpenKai2.exe** for the portable app, **OpenKai2-windows-x64.zip** to
extract manually, or **OpenKai2-Setup.exe** to install. The original Budokai 2
USA ISO is required at every launch. Checksums are in **SHA256SUMS.txt**.
