# v0.2.5

- Remove the Profile button from the launcher header. Use **Customize profile**
  on Play to change your initials, accent and tagline.
- Scroll split lists and timing rules with the mouse wheel without moving the
  launcher page. Scrolling follows the control under the pointer, including
  when another control has keyboard focus. Reaching the end of a list keeps
  the page in place.
- Browse the overlay's split list while speedrun mode is off. Choose a category
  on Speedrun to edit its split names and images.
