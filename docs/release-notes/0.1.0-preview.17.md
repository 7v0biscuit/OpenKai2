This preview fixes the missing screen-fade callback in the latest startup log.
Asset relocation now completes; the main thread next stops at a call from
`0x00249B84` to the fade renderer at `0x002492D0`.

The fade table's 20 slots share four renderers, all merged into a larger function
without callable entries. Translation hints now expose all four. The build
verifies the original table, including its repeated and reserved slots.

The executable's self-test runs the original update caller and inspects the
black and white overlay command packets, opacity, viewport coverage, queue
bounds, drawing-state restoration, and saved registers. It also checks custom
rendering, completion, completed-state behavior, and inactive fade modes.
Publication requires this regression to pass in the installed Windows application.

The original USA ISO is required at every launch. Host graphics output,
title-screen boot, and gameplay remain unverified. Retain `startup.log` when
testing this development preview.
