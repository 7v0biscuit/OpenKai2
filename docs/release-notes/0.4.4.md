# v0.4.4

Share mods, see conflicts, and better Budokai 3 moves.

- **Export mod… and Install mod…** on the Mods page. Export saves a mod as one
  `.okmod` file to send to someone; Install adds a mod from an `.okmod` or
  `.zip` file. Every file is checked on install, packages that would write
  outside their own mod folder are refused, and a failed install leaves nothing
  behind.
- **Mod conflicts are shown.** When two enabled mods change the same file,
  archive entry, character slot or stage slot, the list marks the later one as
  overriding the earlier one, with how many changes it takes over.
- **Budokai 3 characters do the right move on more buttons.** Budokai 3
  renumbered its moves; importing with Budokai 3 moves now matches them to
  Budokai 2's numbering using Goku from both of your discs. For Goku, 270 of
  the 625 moves Budokai 2 uses now match, up from 138. Re-import a character to
  get the fix.

Both players need v0.4.4 to play together online.

Download **OpenKai2.exe** for the portable app, **OpenKai2-windows-x64.zip** to
extract manually, or **OpenKai2-Setup.exe** to install. The original Budokai 2
USA ISO is required at every launch. Checksums are in **SHA256SUMS.txt**.
