# v0.4.7

Fewer late frames in heavy fights.

- **Drawing work is split across two threads.** The thread that prepares every
  draw was the bottleneck in busy fights, at every internal resolution. Reading
  the game's draw commands and preparing them for the graphics card now happen
  side by side, which roughly halves the work on that thread. Heavy scenes
  should drop fewer frames. If anything looks wrong, set the environment
  variable `OPENKAI2_SYNC_RASTER=1` to go back to one thread, and please send
  your startup log.
- **Automatic internal resolution steps down sooner.** With internal resolution
  set to Automatic, it now lowers the resolution when most frames are late,
  even if the graphics card is not fully busy.

Fixed 4x internal resolution can still drop below 60 FPS in effect-heavy fights
on mid-range graphics cards; 3x or Automatic is smoother there.

Known issue: added spots on the character select screen still show the name
"Random" and borrow another spot's portrait.

Both players need v0.4.7 to play together online.

Download **OpenKai2.exe** for the portable app, **OpenKai2-windows-x64.zip** to
extract manually, or **OpenKai2-Setup.exe** to install. The original Budokai 2
USA ISO is required at every launch. Checksums are in **SHA256SUMS.txt**.
