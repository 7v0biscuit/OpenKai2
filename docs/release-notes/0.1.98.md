# v0.1.98

An RGB accent for the launcher, and imported Budokai 3 stages now have their
fight effects.

- Launcher: a new **RGB (cycling)** accent color slowly moves through every
  color, once round the color wheel per minute, redrawn smoothly at 60 FPS.
  The selected tab, banner and buttons change together.
- Budokai 3 stages: imported stages now bring Budokai 3's fight effects, such
  as dust and impacts when fighters hit the ground. The two games number stage
  effects differently; the import tool now places each effect where Budokai 2
  looks for it. Moving stage objects are not imported yet. Import a stage
  again to get its effects.

Download **OpenKai2.exe** for the portable app, **OpenKai2-windows-x64.zip** to
extract manually, or **OpenKai2-Setup.exe** to install. The original Budokai 2
USA ISO is required at every launch. Checksums are in **SHA256SUMS.txt**.
