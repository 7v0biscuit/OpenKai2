# v0.1.45

Fix the select-screen preview of imported characters, and look into the black
Budokai 3 models.

- Imported characters no longer look zoomed in on the select screen. The
  preview's camera comes from a table with a row per character ID, and the
  unused IDs that imports fill (1, 13, 14 and 19) hold a placeholder row whose
  camera is about a third as far away as Goku's. Every imported character now
  uses its base character's row. Characters imported with earlier versions
  get the fix too; nothing needs importing again.
- Budokai 3 models show in game, move with the Budokai 2 animations, but are
  drawn all black. The cause is not known yet. Their texture headers match
  Budokai 2's exactly, so the difference is either in the texture data or in
  how Budokai 3 meshes refer to their textures. The disc report now dumps
  Krillin's textures and mesh blocks in each game (his model fits across
  them) to compare the two.

The v0.1.44 reports also showed that 33 Budokai 3 models fit Budokai 2
characters, among them Krillin, Yamcha, Videl, Frieza, Cooler (on Frieza),
Cell, Majin Buu, Super Buu, Kid Buu, Dabura, Saibaman and Cell Jr.

To continue on the textures, save the Budokai 3 and Budokai 2 reports with
this version and send both.

Not fixed yet: in Dragon World the character can walk off screen, and the
dialogue text and the Yes/No prompt after character select are invisible.

The original USA ISO is required.
