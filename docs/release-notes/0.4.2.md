# v0.4.2

Motion smoothing removed.

- **Motion smoothing** from v0.4.1 is removed. On real high refresh rate
  monitors it produced scanlines and overlapping copies of the picture in both
  modes. The game draws frames exactly as in v0.4 again. If you turned it on, the
  saved setting is ignored.

Both players need v0.4.2 to play together online.

Download **OpenKai2.exe** for the portable app, **OpenKai2-windows-x64.zip** to
extract manually, or **OpenKai2-Setup.exe** to install. The original Budokai 2
USA ISO is required at every launch. Checksums are in **SHA256SUMS.txt**.
