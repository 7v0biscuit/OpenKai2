This preview adds a missing movie packet callback that ended the movie worker
in the Preview 24 log. Thread priorities and startup drawing now advance, and
the parser consumes movie data before calling the unregistered private-stream
handler at 0x001915F0.

All four handlers in the original packet-type table are now reviewed translation
entries. ELF validation checks the table, and generated-source validation checks
each handler's exact resume point. The complete reviewed-entry set has 156 entries.

The regression executes the original caller and packet-info query, routes the
logged 2,030-byte private body through the actual handler and SJRBF methods, and
checks ring wraparound, backpressure, incomplete and empty bodies, result flags,
source/configuration preservation, saved registers, and memory boundaries. It
also checks the disabled-stream paths of the audio/video handlers and the fourth
packet handler. The previous translation reproduces the missing-handler failure.
Windows publication requires this regression in the installed app's self-test.

This verifies packet transport with synthetic data. Movie decoding, title-screen
boot, gameplay, and the visible result still need testing with the original USA
ISO, which remains required at every launch.
