# v0.1.43

The import tool shows which Budokai 3 models fit which Budokai 2 characters.

In v0.1.42 the Import button stayed off with no clear reason when a Budokai 3
model did not fit the chosen character. Budokai 3 remade many characters'
models, Goku's among them: its Goku models are about 690 KB where Budokai 2's
are about 440 KB, and their parts link differently, so Budokai 2's Goku
animations cannot move them.

Now:
- Each model in the list says who can wear it ("fits Goku", "fits Piccolo +2")
  or "no Budokai 2 match".
- Choosing a model marks the spots whose character can wear it with "fits",
  and moves to the first of them.
- When the chosen character can't wear the model, the sentence beside Import
  gives the two part counts and names the characters that can.
- The disc report lists every character's model with its part count and a
  check value; models with the same check value fit each other.

Models with no Budokai 2 match cannot be imported yet: that needs their
skeletons and animations converted, which is not done.

Not fixed yet: in Dragon World the character can walk off screen, and the
dialogue text and the Yes/No prompt after character select are invisible.

The original USA ISO is required.
