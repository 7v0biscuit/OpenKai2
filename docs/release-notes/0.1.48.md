# v0.1.48

A test to find why Budokai 3 models are drawn black.

A copy of a Budokai 2 character in the same kind of character ID looks normal
in game, so the black comes from the Budokai 3 model itself. Its mesh and
textures match Budokai 2's in every header the reports show, so the import
tool can now add one Budokai 3 model in four versions at once, to see in game
which part Budokai 2 draws wrongly.

Choose a Budokai 3 model and its wearer, choose **Compare 4 versions (test)**
under **On the select screen**, and import. Four characters share the
wearer's spot; press R2 there to go through them, in this order after the
character already there:
- A: the model as normally imported (textures marked version 1);
- B: the model exactly as on the Budokai 3 disc;
- C: the Budokai 3 mesh with the wearer's own Budokai 2 textures;
- D: the wearer's own Budokai 2 mesh with the Budokai 3 textures.

The message after importing gives each version's character ID, and the
`[mods] select:` lines in `startup.log` name the ID shown after each R2.
Please say which of A to D look right and which are black. That tells
whether the mesh, the textures or the texture marking is at fault, and if B
looks right, it is the fix.

Comparing uses four unused character IDs.

Not fixed yet: Budokai 3 models are drawn black. In Dragon World the character
can walk off screen, and the dialogue text and the Yes/No prompt after
character select are invisible.

The original USA ISO is required.
