# v0.1.42

The import tool can add Budokai 3 character models to Budokai 2.

Choose a Budokai 3 USA disc in the import tool. The list on the left now
holds Budokai 3's character models, one row per form or costume. Choose a
model, then a Budokai 2 character with the same body to wear it. The tool adds
a new character: a copy of that Budokai 2 character, with its moves,
animations and voice, wearing the Budokai 3 model. It shares the character's
spot (R2 switches) or gets a new spot of its own, as with other imports, and
nobody is removed.

How it works:
- Budokai 3's character table is read from its executable. Its models are
  meshes and textures in the same containers Budokai 2 uses.
- Before importing, the tool checks that the Budokai 3 model links its parts
  the same way as the Budokai 2 character's model, so the Budokai 2
  animations can move it. If they don't, the tool says so and Import stays
  off. The same character in both games usually fits.
- Budokai 3 marks its textures version 2; their headers match Budokai 2's
  version 1 exactly, so imported textures are marked version 1.

Limits:
- Budokai 3 models have not been tried in game yet. Please try one, such as
  a Budokai 3 Goku model on Budokai 2's Goku, and report what you see, with
  `startup.log`.
- Only models are imported. Budokai 3 movesets, stages and capsules use
  formats that differ from Budokai 2's and are not converted.
- Characters that exist only in Budokai 3 need a Budokai 2 character with the
  same body to wear them, so many of them will not fit yet.

Not fixed yet: in Dragon World the character can walk off screen, and the
dialogue text and the Yes/No prompt after character select are invisible.

The original USA ISO is required.
