This preview fixes the missing CD/DVD file-search RPC service (`0x80000597`)
identified in the latest startup log. Earlier previews incorrectly attributed
this bind wait to the sound server.

The service searches the mounted original ISO and returns actual file sectors,
sizes, names, dates, and attributes. It supports all three search packet layouts,
including the 300-byte form used by the game. Failed searches and invalid input
return failure; the original ISO remains required at every launch.

Integration tests cover EE SIF bind and call completion, all packet layouts,
guest address aliases, memory boundaries, missing files, and invalid or removed
ISOs. The old runtime fails the same service-bind check.

Title-screen boot and gameplay remain unverified. This is a development preview;
test it with your original USA disc image and retain the startup log.
