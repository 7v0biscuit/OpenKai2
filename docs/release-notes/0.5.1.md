# v0.5.1

Online matches that start, without port forwarding, and smooth frame rates
with HD textures.

- **Online matches start reliably.** When a match went through the online
  service, the host sent the starting state of the game to the other player
  and gave up after 20 seconds with "The other player stopped responding" if
  it had not arrived yet. The host now waits up to five minutes for the other
  player to load the match, and shows that it is waiting. The joining player's
  game also waits up to three minutes for a host that is still starting up.
- **No port forwarding.** When a player can't reach a room directly, the two
  launchers now open a direct connection through both routers (UDP hole
  punching) after meeting through the online service. This works with most
  home routers and gives the ping of a direct connection. Only if the routers
  block it does the match go through the online service. The launcher log says
  which one each match used.
- **Lower latency on a direct connection.** A lost packet is sent again after
  about one and a half round trips instead of a fixed 0.4 seconds, so a dropped
  packet no longer freezes the match for a moment.
- **Smaller starting state.** The game state sent when a match starts is
  compressed to about 14 MB instead of 24 MB, so matches start faster.
- **HD textures no longer slow down the game.** In v0.5, HD textures could drop
  fights to 30-40 FPS on fast PCs because each texture's HD lookup was redone
  every few hundred draws. Lookups now stay cached until the texture actually
  changes, and HD texture work no longer costs the graphics thread more than
  having HD textures off.
- **No hitches when new textures appear.** New textures are decoded and hashed
  on the texture threads instead of the graphics thread, and local upscaling is
  about 25% faster with identical results.

Both players need v0.5.1 to play together online.

Download **OpenKai2.exe** for the portable app, **OpenKai2-windows-x64.zip** to
extract manually, or **OpenKai2-Setup.exe** to install. The original Budokai 2
USA ISO is required at every launch. Checksums are in **SHA256SUMS.txt**.
