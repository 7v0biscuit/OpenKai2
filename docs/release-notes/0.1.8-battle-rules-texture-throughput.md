# Battle rules and texture throughput

This release addresses an unregistered battle-rule call reached after the
fight introduction and reduces CPU texture-sampling overhead.

- Register all 20 distinct methods in the fight initialization, update, and
  result-rule tables, including the target at `0x1d34f0`.
- Exercise the original rule call site in 896 native cases covering timers,
  knockouts, ties, state commands, and preserved registers.
- Pass texture caches directly through sprite and triangle sampling to remove
  repeated thread-local lookups.
- Add an optional 40-case texture benchmark covering filtering, indexed
  textures, perspective, small draws, and feedback.

Windows binary benchmarks under Wine measured about 29–36% lower serial
bilinear draw times and 3–24% lower point-filtered draw times. All reference VRAM
checksums matched with one and four workers. These synthetic measurements do
not establish retail game FPS.

The original USA ISO is required at every launch. Uninterrupted retail matches
and sustained 60 FPS remain unverified. The runtime uses CPU graphics; complete
SPU2 synthesis and retail audio fidelity remain incomplete.
