# v0.1.57

Battle callbacks and frame pacing.

- Register the original battle task dispatch table and all three melee interaction banks. This supplies the missing task at `0x001bc0b0`, the clash entry at `0x001d8220`, and its update at `0x001d8240`. The executable digest, table contents, and entry instructions are verified before translation.
- Request presentation from guest VBlank instead of window polling, so a late window swap does not delay submission of the next field. Simulation timing remains unchanged.
- Queue native texture uploads alongside GIF packets. Uploads own their source bytes and preserve ordering without draining the graphics worker at each upload.
- Replace general division and remainder operations in GPU swizzled addressing with verified page shifts and masks across all 13 supported storage formats.
- Reject depth-occluded pixels before texture sampling and filtering. Convert constant point, sprite, and triangle depths once per draw while retaining the original rounding rules.

Validation covers original translated callbacks, phase changes, saved registers, guest memory aliases, presentation without window polling, queued upload ordering and ownership, and CPU/GPU video-memory comparisons.

Stable 60 FPS across gameplay, complete story progression, hair and limb deformation, and the reported music dropouts remain unverified. The performance changes do not alter animation speed or enable frame generation.
