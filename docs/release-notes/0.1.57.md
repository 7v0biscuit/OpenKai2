Validation covers original translated callbacks, phase changes, saved registers, guest memory aliases, presentation without window polling, queued upload ordering and ownership, and CPU/GPU video-memory comparisons.

Stable 60 FPS across gameplay, complete story progression, hair and limb deformation, and the reported music dropouts remain unverified. The performance changes do not alter animation speed or enable frame generation.

## Budokai 3 textures

A real bug behind the black and blue Budokai 3 textures, found from your
test: every version that repacks the Budokai 3 textures was black, including
the normal import, while a plain Budokai 2 copy drew right.

Each texture's pixels and palette come after 32 bytes that send them to the
console's video memory, and the texture's header gives the size without
those 32 bytes. The import tool cut each piece at that size, so it lost the
last 32 bytes of every texture and every palette: half the colours of a
16-colour palette came out black or as stray data. The tool now copies all
of it.

- **Normal imports** of Budokai 3 characters (the textures on a Budokai 2
  body) should now show their colours. Delete the mods made with earlier
  versions and import them again.
