# v0.1.58

Fixes the screen shaking that came with v0.1.57.

The PS2 shows Budokai 2 interlaced: alternate fields sit one line apart, and
the picture is placed by the field's parity to match. v0.1.57 started
presenting from the game's VBlank instead of the window loop, but it asked
for the picture at the very start of VBlank, before the game's VBlank
handlers choose the buffer for the new field. Whether the old or the new
buffer was captured then varied from frame to frame while the parity had
already moved on, so the shift no longer cancelled and the picture bounced.
Presentation is now requested at the end of VBlank, when the new field
starts scanning out, as on the console.

Frame timing from your v0.1.57 log, against the one before it: frames over
25 ms fell from 11.1% to 5.9%, the 95th percentile from 32 to 27 ms and the
99th from 42 to 32 ms. The game itself still runs at 96.5% speed (57.9
fields a second), and DMA handling (about 56 µs per submission, half a
million times in two minutes) is now its largest cost.

Not fixed yet: a crash reported on v0.1.57, waiting on its log. In Dragon
World the character can walk off screen, and the dialogue text and the Yes/No
prompt after character select are invisible.

The original USA ISO is required.
