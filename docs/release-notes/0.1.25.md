# v0.1.25

Add a desktop launcher with ISO verification, saved preferences, and save recovery.

- Remember the verified ISO path and check the game files before every launch.
- Add Play, Saves, Settings, and Updates pages using native Windows controls and an
  orange, navy, and gold palette.
- Import PSU saves, extracted save folders and OpenKai2 ZIP snapshots. Back up
  the active card before imports/restores and optionally before/after play.
- Save renderer, FPS limit, resolution, display mode, VSync, FXAA, texture
  filtering, aspect ratio, and nearest/bilinear/bicubic scaling preferences.
- Restore a 60 FPS default and prevent overdue host vertical blanks from
  producing bursts of catch-up animation after a stall.
- Register the complete Dragon World callback bank, including its missing
  completion method, and check the original callback's behavior.
- Skip repeated-vertex and axis-flat triangles before GPU tile processing.
- Check GitHub releases automatically with stable and prerelease channels.
  Verify package checksums, update portable or installed copies between sessions,
  and recover original application files if replacement fails.
- Accelerate Windows ISO hashing through the operating system SHA-256 provider
  while retaining full file verification.
- Keep file logging independent of console availability for launcher and
  background game processes.

The original USA ISO is required. Host audio remains disabled. Complete story
progression, character pose correctness, stable 60 FPS and complete matches
remain under development. FSR and frame generation are not included.
