# v0.2.0

Faster loading when you want it, and steadier audio.

- Load times: **Settings > Game > PS2 load times** chooses between
  **Accurate (PS2)**, where disc reads take as long as on a real PS2 drive,
  and **Fastest (this PC)**, where loading screens pass almost instantly.
  Speedrun mode always uses PS2 load times so every run is timed the same.
- Audio: the thread that feeds your sound card now runs at pro-audio
  priority with a slightly larger buffer, so heavy moments in the game are
  less likely to cause pops or brief cut-outs. When the game closes,
  `startup.log` notes how often the sound card had to wait, which helps track
  down any pops that remain.

Download **OpenKai2.exe** for the portable app, **OpenKai2-windows-x64.zip** to
extract manually, or **OpenKai2-Setup.exe** to install. The original Budokai 2
USA ISO is required at every launch. Checksums are in **SHA256SUMS.txt**.
