This preview fixes incompatible MPEG SDK setup used by the Sofdec movie player.
The reported retail run displays images/logos, then turns black; pressing Start
does not advance it. The graphics reports confirm changing nonblack frames
before that transition, with no execution exception.

The generic MPEG replacement uses a different work-area layout, returns an
allocator pointer instead of SDK success, writes unrelated fixed globals, and
keeps callbacks outside the guest table that the native decoder reads.
OpenKai2 now translates the game's original create, reset, reference-clear,
callback-registration, and IPU-sync routines. There are 152 reviewed entries.

The executable self-test executes the original SDK routines through return.
It checks aligned and unaligned work buffers, allocator and
reference pointers, callback/data/GP records, the original dispatcher calling
the compiled Sofdec no-data handler, reset, neighboring memory, saved registers,
and preservation of unrelated guest globals. Publication requires this check to
pass in the installed Windows application.

Movie reports now follow the live game handle and read the movie backend's
actual status word. Activation and state changes are captured immediately;
periodic snapshots are timed from activation so logo frames cannot consume
them. Reports include the movie filename, SDK error, and scene callback and
remain bounded and read-only.

Movie playback, title-screen boot, and gameplay remain unverified. The original
USA ISO is required at every launch. Retain the new `startup.log` if the screen
still turns black after the logos.
