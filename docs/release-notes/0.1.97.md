# v0.1.97

Dragon World text is back, loads take as long as on a PS2, and imported
Budokai 3 characters keep their colors.

- Dragon World: the story dialogue and the Yes/No labels show again. The game
  compared two values with a vector maximum that came out as "not a number",
  which hid the text.
- Loading: the game's own disc reads now take the time a PS2 drive takes
  (4x DVD, 30 to 100 ms seeks), so loading screens last as long as on a
  console.
- Budokai 3 imports: characters imported from Budokai 3 no longer show up
  black, gray, white or blue. Budokai 3 colors skin and clothes through its
  shading textures, which Budokai 2 drew over the whole body; the import tool
  now converts them to Budokai 2's shading. Import a character again to get the
  fixed colors.

Download **OpenKai2.exe** for the portable app, **OpenKai2-windows-x64.zip** to
extract manually, or **OpenKai2-Setup.exe** to install. The original Budokai 2
USA ISO is required at every launch. Checksums are in **SHA256SUMS.txt**.
