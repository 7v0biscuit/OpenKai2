# v0.2.3

A tidier sidebar and clearer page headers.

- Sidebar: the System tabs are now in the order **Controls**, **Settings**,
  **Updates**. If you updated from v0.2.2, Controls moves ahead of Settings and
  Updates once; after that, any order you choose under **Arrange tabs** is kept.
- Arrange tabs: resetting the tab order works again with the Controls tab.
- Page headers: every page title has an icon matching its sidebar tab.

Download **OpenKai2.exe** for the portable app, **OpenKai2-windows-x64.zip** to
extract manually, or **OpenKai2-Setup.exe** to install. The original Budokai 2
USA ISO is required at every launch. Checksums are in **SHA256SUMS.txt**.
