# v0.6.6

A cleaner launcher and new profile frames.

- **New launcher font.** The launcher now uses Inter in normal sentence case
  instead of the comic-style capitals, with smoother grayscale text over the
  animated backgrounds. Setting names read "Window mode" instead of "WINDOW
  MODE", and the selected item on the Wave home is lighter and larger.
- **Space profile frames.** All fifteen frames are redrawn as space designs:
  Orbit, Lunar silver, Eclipse, Binary stars, Ringed planet, Nebula halo, Star
  crown, Gravity wave, Event horizon, Aurora, Comet, Constellation, Blue giant,
  Solar corona and Stardust. Each has a soft shadow, metallic shading and glow
  so it stands out from the card behind it. Equipped frames keep their slot.
