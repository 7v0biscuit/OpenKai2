This preview addresses the missing indirect startup method at `0x001908E0`.
The latest log confirms that sound initialization progresses and the memory-card
and controller modules load before this dispatch failure.

The translation now registers all 98 methods in seven reviewed subsystem tables;
the previous build omitted 86 entries. The entry metadata is verified against
the supported USA executable, and every generated binding must resume at its
own instruction. Original translated implementations remain in use.

The installed executable's self-test checks method registration, executes 39
original leaf callbacks, verifies return delay slots and preserved registers and
stack, and exercises their compiled startup caller. Release publication requires
these checks to pass on Windows.

The original USA ISO is required at every launch. Title-screen boot and gameplay
remain unverified; retain the startup log when testing this development preview.
