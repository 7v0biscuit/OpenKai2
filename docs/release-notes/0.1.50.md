# v0.1.50

Force any Budokai 3 model into Budokai 2 as a new character.

- **Force a new character**, under **On the select screen** when the source
  is a Budokai 3 disc, imports the whole Budokai 3 model (mesh and textures)
  as a new character with a spot of its own, whether or not it fits a Budokai
  2 character. Choose whose moves and animations it uses on the right.

Limits:
- Budokai 2 still draws Budokai 3 meshes black, so a forced character is
  black until the meshes can be converted. The moves of the character you
  choose may not suit the Budokai 3 body.
- Budokai 3 stages, movesets and capsules cannot be imported yet. Each uses
  formats that are not mapped: the mesh drawing data, the move tables
  (`#BSK` version 4 against Budokai 2's version 3), Budokai 2's stage table
  and the capsule system, which Budokai 3 changed.

Not fixed yet: in Dragon World the character can walk off screen, and the
dialogue text and the Yes/No prompt after character select are invisible.

The original USA ISO is required.
