# v0.1.84

Correct GS depth-enable behavior and add the recompilation project manifest.

- Honor `TEST.ZTE` in the CPU, OpenGL and Vulkan rendering paths. Disabling
  depth testing now also suppresses depth writes, as on the console.
- Add 512 known-output graphics cases covering depth formats, comparisons,
  write masks and primitive types.
- Add `.recomp.json` for project discovery.

Dragon World testing has verified boss battle returns and reward sequences.
Progression through the Goal into the next stage remains under investigation.
Missing dialogue and confirmation text are also unresolved. This release does
not establish full story completion or stable 60 FPS.

See the [Dragon World validation record](https://github.com/7v0biscuit/OpenKai2/blob/main/docs/dragon-world-validation.md)
for test coverage and limitations.
