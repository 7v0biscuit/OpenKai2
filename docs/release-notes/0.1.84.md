# v0.1.84

Correct GS depth-enable behavior and add the recompilation project manifest.

- Honor `TEST.ZTE` in the CPU, OpenGL and Vulkan rendering paths. Disabling
  depth testing now also suppresses depth writes, as on the console.
- Add 512 known-output graphics cases covering depth formats, comparisons,
  write masks and primitive types.
- Add `.recomp.json` for project discovery.

Known issues:

- Dragon World can fail to advance after reaching the Goal following the
  Raditz and Nappa fights.
- Some Dragon World dialogue and confirmation text is missing.
- Music quality needs improvement, and tracks can stop after fights or scene
  changes.
- The snow stage still has frame-rate drops. Most gameplay outside this stage
  runs at roughly 60 FPS.

Full Dragon World completion is still being tested.

See the [Dragon World validation record](https://github.com/7v0biscuit/OpenKai2/blob/main/docs/dragon-world-validation.md)
for test coverage and limitations.

Download **OpenKai2.exe** for the portable app, **OpenKai2-windows-x64.zip** to
extract manually, or **OpenKai2-Setup.exe** to install. The original Budokai 2
USA ISO is required at every launch. Checksums are in **SHA256SUMS.txt**.
