# v0.1.85

Reduce graphics submission overhead and avoid repeated window redraws while
waiting for a game frame.

- Reject fully offscreen triangles before allocating GPU tile work. New
  comparisons cover 96 outside and partially visible triangles.
- Wake the window when a game frame completes. Idle overlays refresh every
  four milliseconds instead of redrawing the same frame thousands of times
  per second in uncapped mode. Keyboard input remains available to overlays.
- Add Dragon World Goal-event and story-flag regression coverage. The stage 1
  Goal transition has passed testing through stage 2 setup and board control.

These changes target snow-stage slowdowns and uneven frame pacing. A steady
60 FPS on that stage still needs confirmation in gameplay. Game speed remains
tied to the original console timing.

Some Dragon World dialogue and confirmation text remains missing. Music quality
and tracks stopping after scene changes remain known issues.

Download **OpenKai2.exe** for the portable app, **OpenKai2-windows-x64.zip** to
extract manually, or **OpenKai2-Setup.exe** to install. The original Budokai 2
USA ISO is required at every launch. Checksums are in **SHA256SUMS.txt**.
