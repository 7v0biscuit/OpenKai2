This preview addresses the missing file-driver callback at `0x00167AF8`.
The latest log passes the subsystem dispatcher and then stops when file handling
calls this method with a null object and query code 100.

The translation now covers all 14 non-null callbacks in the reviewed file-driver
interface bank, including ten previously missing entries. The bank's original
null slots and method addresses are checked against the supported executable.
Original translated implementations remain in use.

The installed executable's self-test executes the query callback across null,
unsupported-command, file-size, and signed-boundary cases. It checks object and
stack memory and saved registers, then exercises the compiled caller with real
query and sector-size callbacks and an absent slot. Release publication requires
this regression to pass on Windows.

The original USA ISO is required at every launch. Full game boot and gameplay
remain unverified; retain the startup log when testing this development preview.
