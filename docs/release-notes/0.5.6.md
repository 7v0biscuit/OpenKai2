# v0.5.6

More exclusive name effects for every name tag key, and a verified badge for
key owners.

- **Three new effects per tag.** [DEV] adds super aura, dragon star and
  galaxy. [TTV] adds chat flood, raid and neon sign. [YT] adds play button,
  premiere and trending. [ToB] adds lava, lightning and venom. Each effect can
  only be used by profiles with that tag's key, and every launcher checks the
  key's signature before showing it.
- **Verified badge.** A player with a signed name effect shows **Verified**
  with their tag, in the tag's color, on their player profile.

Players on v0.5.5 or older see the new effects as a plain name. Both players
need v0.5.6 to play together online.

Download **OpenKai2.exe** for the portable app, **OpenKai2-windows-x64.zip** to
extract manually, or **OpenKai2-Setup.exe** to install. The original Budokai 2
USA ISO is required at every launch. Checksums are in **SHA256SUMS.txt**.
