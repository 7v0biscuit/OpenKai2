# v0.1.87

Faster texture uploads for the snow stage.

- The snow stage sends about a million small snowflake sprites and many 4-bit
  texture uploads in a short fight. Texture uploads are now written a row at a
  time instead of working out each pixel's position from scratch. On a recording
  of that stage, the graphics thread's processor time drops by about 15%.
- Add a benchmark that replays a recorded stream of graphics packets, so
  slow scenes can be measured outside the game.

The snow stage is still being measured on real hardware. If it still drops
below 60 FPS, please attach `startup.log` from a fight on that stage.

Download **OpenKai2.exe** for the portable app, **OpenKai2-windows-x64.zip** to
extract manually, or **OpenKai2-Setup.exe** to install. The original Budokai 2
USA ISO is required at every launch. Checksums are in **SHA256SUMS.txt**.
