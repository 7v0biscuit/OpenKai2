# v0.1.51

Fix special moves of imported characters, match more Budokai 3 models, and
map Budokai 2's stage table.

- Imported characters' special moves work: a Kamehameha draws its beam and
  hits. The game finds a form's move effects in a table indexed by character
  ID, where the unused IDs that imports fill hold -1, so their attacks drew
  nothing and hit nothing. Every filled ID now takes its base character's
  entry there, and in four more tables the unused IDs leave empty: two of
  voice files, the name plate and hair physics. Characters imported with
  earlier versions get the fix without importing again.
- A new matcher fits more Budokai 3 models to Budokai 2 characters: for each
  of the Budokai 2 character's textures, in order, it takes the next Budokai 3
  texture with the same format and size, skipping the rest, and builds a
  texture pack in the Budokai 2 layout. Before, the Budokai 3 textures had to
  start with exactly the Budokai 2 character's.
- Budokai 2's stage table is mapped: 13 stages of 156 bytes at `0x373270`,
  each naming its eight files. The disc report lists them, and dumps Budokai
  3's stage records to map them next. Stages cannot be imported yet.

Limits:
- The move-effects table covers IDs 0 to 40. The import tool fills IDs 1, 13,
  14 and 19 first; a character filled in ID 43 or above may still have
  special moves that do not work, and the import tool says so.
- These fixes are checked by unit tests against the USA executable's tables,
  not yet in game. Please try a special move with an imported character.
- Budokai 3 meshes, movesets, stages and capsules still cannot be converted.

Not fixed yet: in Dragon World the character can walk off screen, and the
dialogue text and the Yes/No prompt after character select are invisible.

The original USA ISO is required.
