# v0.5

Sharper HD textures, faster higher internal resolutions, and correct names on
added select-screen spots.

- **HD textures reach much more of the picture.** About half of the game's
  textured drawing never got an HD texture: a texture uploaded into video
  memory that the graphics card had drawn to before was always skipped. These
  textures now get HD versions too. Textures the graphics card draws over are
  still left as they are.
- **Sharper upscaled textures.** Local upscaling now follows the edges and
  shading of the game's painted textures instead of doubling texels, so
  outlines stay smooth and continuous and gradients stay even. Menus, text and
  other pixel-exact 2D art keep their original textures; texture packs still
  replace everything they cover.
- **HD textures stay loaded.** Upscaled textures are kept in video memory and
  only the least recently used ones are dropped when space runs out, instead of
  dropping all of them. Large textures are upscaled 2x instead of 4x, which
  looks the same on a 1080p screen and fits four times as many. Upscaling uses
  up to three threads on PCs with more cores.
- **Less work for the graphics card at higher internal resolutions.** Hidden
  pixels are now rejected before their colour and texture coordinates are
  worked out, and each triangle is set up once instead of for every pixel. A
  recorded fight at 4x drew about 16% faster with an identical picture.
- **Less work on the game's main thread.** The emulated console's hardware
  registers are kept in a simple table, which made the game thread about 8%
  faster in a fight, and HD texture sources are read straight from video
  memory. This helps most on older processors.
- **Added select-screen spots show a name.** A spot added by a mod now shows
  the name of the spot whose portrait it uses instead of "Random".

The startup log now splits the graphics card's time into native drawing,
higher-resolution drawing, uploads, copies and preparing the final picture
(Vulkan only).

Both players need v0.5 to play together online.

Download **OpenKai2.exe** for the portable app, **OpenKai2-windows-x64.zip** to
extract manually, or **OpenKai2-Setup.exe** to install. The original Budokai 2
USA ISO is required at every launch. Checksums are in **SHA256SUMS.txt**.
