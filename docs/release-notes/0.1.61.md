# v0.1.61

Turns stage import off, which froze the game.

A Budokai 3 stage imported into Town B froze the game when you chose it.
The first log showed Budokai 2's pack loader calling address 0; the second
(from v0.1.59) a jump to `0x231712`, garbage read as code. So Budokai 3's
stage files don't load correctly in Budokai 2 as they are, and the check
added in v0.1.60 doesn't catch every case.

- Stage mods are no longer applied. The startup log says how many were
  skipped. Town B and the other stages are the originals again, so choosing
  them no longer freezes.
- The import tool's Stages tab lists stages again and says why they can't be
  imported yet.
- Nothing else changes: characters, movesets and the Mods page work as in
  v0.1.59.

Stages can come back once their files are converted. A disc report from your
Budokai 3 disc (Disc report… in the import tool) lists the file kinds in each
stage, which is the first step.

Not fixed yet: in Dragon World the character can walk off screen, and the
dialogue text and the Yes/No prompt after character select are invisible.

The original USA ISO is required.
