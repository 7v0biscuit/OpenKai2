This preview fixes the missing `AMM` asset relocation entry reported in the
latest startup log. Sound transfer now completes; the main thread next stops
when the original asset dispatcher calls `0x0012AC30` from `0x0012A75C`.

The stripped-ELF analyzer merged seven asset handlers into a larger function
without callable entries. Translation hints now expose every handler in the
original tagged table: AMG, AMT, AMM, AMO, AMC, AML, and AMP. The build verifies
their original addresses, tags, and terminating record.

The executable's self-test runs the original dispatcher with the logged object
address and checks populated and empty records, nested assets, relative pointer
relocation, adjacent memory, saved registers, and repeated-call guards.
Publication requires this regression to pass in the installed Windows application.

The original USA ISO is required at every launch. Title-screen boot and gameplay
remain unverified. Retain `startup.log` when testing this development preview.
