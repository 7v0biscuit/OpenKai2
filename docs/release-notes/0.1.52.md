# v0.1.52

A likely fix for the black Budokai 3 bodies.

The v0.1.51 reports compare Supreme Kai's mesh in both games block by block.
Every block has the same size, and the second block is identical word for
word except for one 16-byte material record: flags, `0x29BD` and two texture
numbers. Budokai 2 sets bit `0x2000` in the flags (`0x21B5`); Budokai 3 leaves
it clear (`0x01B5`). Krillin's mesh shows the same. The texture numbers follow
each game's own texture order, which is right while a Budokai 3 mesh keeps
its own textures.

Forced imports now set that flag in every Budokai 3 material record, so
Budokai 2 should draw a forced Budokai 3 body with its colours. The **A**
version of **Compare 4 versions** does too.

- Characters forced in with v0.1.51 or earlier keep the unflagged mesh;
  import them again with this version.
- This is checked by unit tests and the reports, not yet in game. Please force
  a Budokai 3 character again and say whether its colours show.
- The disc report lists Krillin's and Supreme Kai's material records in both
  games, to check the pattern holds in every block.

Not fixed yet: in Dragon World the character can walk off screen, and the
dialogue text and the Yes/No prompt after character select are invisible.

The original USA ISO is required.
