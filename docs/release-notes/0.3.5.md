# v0.3.5

Launcher fixes.

- Turning the mouse wheel over a closed dropdown no longer changes the
  setting. The page scrolls instead. Open a dropdown to scroll through its
  choices.
- Settings no longer fail with "Cannot read settings" or "Cannot replace
  settings file" when the launcher and the game open the settings file at
  the same moment.

Includes the rollback netcode from v0.3.4. Both players need the same version
to play online.

Download **OpenKai2.exe** for the portable app, **OpenKai2-windows-x64.zip** to
extract manually, or **OpenKai2-Setup.exe** to install. The original Budokai 2
USA ISO is required at every launch. Checksums are in **SHA256SUMS.txt**.
