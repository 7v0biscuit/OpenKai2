# v0.4.9

Smoother play on older PCs and graphics cards, and online matches that start
reliably.

- **Much less work for older graphics cards.** Depth in 3D scenes was worked
  out with 64-bit math, which many graphics cards, including GTX 10-series
  cards, run far slower than normal math. It now uses exact 32-bit math
  instead. The picture is the same. This also lets Vulkan run on cards that
  do not support 64-bit math at all.
- **Less waiting on the graphics card.** Native and higher internal resolution
  drawing now run together instead of one after the other.
- **3D geometry moved off the game's main thread.** Turning the game's 3D
  models into drawing commands now happens on its own thread, in the same
  order as before, so the game's main work has more room on slower processors.
  If anything looks wrong, set the environment variable
  `OPENKAI2_DMA_THREAD=0` to turn this off, and please send your startup log.
- **Online matches start once.** After a room connected, the launcher could
  start the match twice. That could open two game windows, and the one you
  were left with never heard from the other player. Each room now starts
  exactly one match.
- **Faster fallback to the online relay.** When the host's port is not
  forwarded, joining now switches to the online relay after a few seconds
  instead of waiting about 20.
- **More time to start a match on slower PCs.** Both games now have five
  minutes to start once a room connects, instead of 60 to 90 seconds.
- **Clearer online logs.** The launcher log now records each step of joining
  or hosting a room.

The startup log now reports how busy the graphics card is every 30 seconds
(Vulkan only).

Known issue: added spots on the character select screen still show the name
"Random" and borrow another spot's portrait.

Both players need v0.4.9 to play together online.

Download **OpenKai2.exe** for the portable app, **OpenKai2-windows-x64.zip** to
extract manually, or **OpenKai2-Setup.exe** to install. The original Budokai 2
USA ISO is required at every launch. Checksums are in **SHA256SUMS.txt**.
