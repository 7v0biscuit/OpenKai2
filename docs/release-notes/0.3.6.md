# v0.3.6

Launcher scrolling.

- The launcher no longer shows a scroll bar. Scroll pages with the mouse
  wheel, as before.
- The mouse wheel now scrolls the page when the pointer is over a list or text
  box that has nothing to scroll. Lists that do overflow still scroll on
  their own.
- Includes v0.3.5: the mouse wheel no longer changes closed dropdowns, and
  settings no longer fail to load or save when the launcher and the game use
  them at the same moment.

Both players need the same version to play online.

Download **OpenKai2.exe** for the portable app, **OpenKai2-windows-x64.zip** to
extract manually, or **OpenKai2-Setup.exe** to install. The original Budokai 2
USA ISO is required at every launch. Checksums are in **SHA256SUMS.txt**.
