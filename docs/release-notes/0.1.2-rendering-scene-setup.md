Faster common CPU rendering paths and complete scene-mode callback registration.

## Changes

- Register all seven handlers in the scene-mode table, including `0x001B3070`. Verify the original table and complete handler instructions against the supported executable.
- Exercise both table halves and scene variants through the original indirect caller, checking animation records, flags, frame state, and saved registers.
- Prepare unmasked CT32 pixel writes once per sprite or triangle. Support depth writes, predecoded blend selectors, opaque source-over, and PABE behavior without repeating general pixel-state decoding.
- Retain the general path for alpha/destination tests, framebuffer masks, fog, and formats. Preserve color/depth ordering for overlapping buffers.
- Add 64 complete-VRAM comparisons against the previous renderer, including dependent texture-cache samples and alpha/depth boundaries.

Twelve indexed-texture microbenchmarks measured 7–16% lower median draw times over three runs per version. Large parallel and small serial draws retained identical VRAM output. These measurements are not game-FPS results.

## Status

This update addresses a missing stage-setup callback and reduces common CPU rendering overhead. Complete matches and stable 60 FPS remain unverified; character and stage loading still require full retail validation. The movie decoder and audio implementation are unchanged.

The original Budokai 2 USA ISO is required at every game launch. Game files are not included.
