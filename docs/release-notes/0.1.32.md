# v0.1.32

Remove most GPU stalls in fights, give V2/V3 vertex uploads their console values, and fix music quality and fight audio skipping.

- Run texture uploads into, and VRAM copies out of, pages the GPU has drawn
  as GPU compute jobs. Each one used to read VRAM back and wait for the GPU;
  in the last fight log those waits took 25 of 96 seconds.
- Write the console's lane values for VIF V2, V3 and V4-5 unpacks. V2 now
  writes X Y X Y, V3 takes W from the next element, and V4-5 colours are
  widened to eight bits. Before, those lanes kept stale data from earlier
  uploads, a candidate cause of the distorted limbs and hair in fights.
- Play audio sample for sample at full speed. The time-stretcher used to
  keep nudging its rate near full speed, which made music warble.
- Follow the game's real audio production rate down to 25% speed. Fights ran
  below half speed, slower than the stretcher could go, so audio ran dry,
  skipped and drifted out of sync.
- Report GPU transfer counts in the startup log (`gpu_transfers=`).

The original USA ISO is required. These changes are verified by unit and
GPU comparison tests and need in-game confirmation.
