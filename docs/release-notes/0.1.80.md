# v0.1.80

Dragon World callback coverage and safer GPU transfers.

## Game

- Translate five missing indirect callbacks used by scene changes, Dragon World
  fades, board overlays and the ending. The original game instructions are
  preserved, including waiting and Start-button handling.

## Graphics

- Split large image uploads across two compute dimensions. A full 2048-by-2048
  indexed upload exceeded the dispatch limit in OpenGL and Vulkan, which could
  leave incorrect graphics data or cause driver-dependent failures.
- Size the HD-texture cache to the device's storage-buffer limit. Internal
  resolutions whose render targets cannot fit use native rendering.
- Add complete-VRAM comparisons on both sides of the large-upload boundary.

## Development

- Restore Windows component builds and ensure every registered test is built.
- Fix test references and open file handles that caused false failures on Windows.

Full Dragon World completion remains unverified. The original USA ISO is required.
