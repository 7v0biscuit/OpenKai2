This diagnostic preview investigates the unresolved CRI RPC startup stall.
The latest retail log confirms three IOP threads start, but does not identify
which waits prevent the server from registering.

Pending RPC diagnostics now include bounded thread states, semaphore counts,
event bits, wake deadlines, nearby guest instructions, and recent import calls.
The scheduler also reports exceptions that were previously suppressed. Active
CPU context is restored when a guest call unwinds through an exception.

Regression checks verify that taking a snapshot does not change guest memory,
release a semaphore, or wake an event waiter. The original ISO is still required
at every launch. This preview does not establish a fix for the retail startup
stall; title-screen boot and gameplay remain unverified.
