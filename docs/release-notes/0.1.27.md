# v0.1.27

Expand animation-script coverage and reduce rendering transfers and repeated filtering.

- Register 485 scene and actor script commands, preserving complete static banks
  and their root table. Include the pod-status and actor-state commands that
  stopped execution during the opening story sequence.
- Register 79 callbacks installed by object constructors, including the story
  wait callback used after the pods land. Check the constructor's delay-slot
  store and the update callback's half-frame completion boundary.
- Execute the original guest instructions for status flags and signed actor
  state, with return values and caller registers checked across memory aliases.
- Read back the color surfaces needed for presentation. Keep depth and unrelated
  render targets on the GPU until another consumer requests them.
- Reuse completed FXAA, bicubic and FSR 1 output between game frames. Invalidate
  filtered output when a frame, source crop, filter or output size changes.
- Add a fuller launcher game panel, graphics and save shortcuts, outlined
  secondary actions, navigation descriptions and grouped settings cards.
- Record filtered-frame processing and reuse counts on shutdown.

The original USA ISO is required. Host audio remains off. Complete story
progression, pod visibility, character poses and stable 60 FPS still require
validation. FSR 1 is spatial upscaling; FSR 3/4 and frame generation remain
unavailable.
