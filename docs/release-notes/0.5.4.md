# v0.5.4

New [TTV], [YT] and [ToB] name tags, profile renaming, and name effects that
always animate.

- **[TTV], [YT] and [ToB] name tags.** Each tag has its own key file from the
  developer. Type a name with the tag and the launcher asks for the key once;
  after that any of your profiles can carry the tag with any name. Other
  players' launchers check each tag's signature, so a tag without its key is
  removed.
- **Rename profiles.** **Rename** beside **New profile** on Online renames the
  active profile and keeps its tag: `[TTV] Biscuit` can become `[TTV] Joint`
  by typing only `Joint`. Friends, picture and stats stay with the profile.
- **Name effects always animate.** The [DEV] name effects stopped moving when
  Windows animations were turned off or the launcher was not the focused
  window. They now always animate, slowly when the launcher's Reduced motion
  is on. Animated avatar accents on other players' cards move too. Name
  effects remain [DEV] only.
- **Quicker profiles.** Press Enter on a name in Players or Friends to open
  that player's profile, and invitations and friend requests show the
  sender's picture, name color and card.
- **Remembered friends view.** Play's Friends panel keeps the view you chose
  (all, online, everyone or recent opponents) between launches.

Both players need v0.5.4 to play together online.

Download **OpenKai2.exe** for the portable app, **OpenKai2-windows-x64.zip** to
extract manually, or **OpenKai2-Setup.exe** to install. The original Budokai 2
USA ISO is required at every launch. Checksums are in **SHA256SUMS.txt**.
