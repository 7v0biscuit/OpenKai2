# v0.3.7

Launcher fixes.

- Scrolling no longer smears the page. Each scroll now redraws the page before
  its buttons, lists and dropdowns, so controls no longer show pieces of the
  page from the previous scroll position.
- "Disc cache is in use; close other instances first" no longer gets stuck
  after OpenKai2 crashes or is closed while checking the disc. The lock is
  released automatically when OpenKai2 exits.

Both players need the same version to play online.

Download **OpenKai2.exe** for the portable app, **OpenKai2-windows-x64.zip** to
extract manually, or **OpenKai2-Setup.exe** to install. The original Budokai 2
USA ISO is required at every launch. Checksums are in **SHA256SUMS.txt**.
