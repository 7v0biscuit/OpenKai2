# v0.1.86

Fix Tournament Z difficulty, apply speedrun setup automatically, and reduce graphics submission work.

- Fix Z1–Z3 in World Tournament. Preserve the original tier and round, target
  the actual CPU side, and initialize its strongest behavior preset from the
  game's data. Add battle diagnostics to confirm the applied settings.
- Reuse graphics command storage and skip appending culled primitives. Reduce
  CPU submission work while preserving the rendered output.
- Disable manual save-state and load-state requests whenever speedrun mode is
  selected. Automatic permadeath resets use an internal checkpoint.
- Prepare a separate memory card for each session. Any% starts empty; NG+
  preserves the original save's unlocks and equipment while clearing unfinished
  Dragon World progress. Closing the game discards the working card and ends
  the attempt. Your original save is unchanged.
- Lock NG+ (Very Hard) to the game's Very Hard setting. Z variants keep their
  selected modifier and strongest game/COM settings.
- Select the matching World Tournament bracket and check its unlock requirements.
  Tournament timing remains manual; F9 controls the timer rather than loading
  a state.
- Confirm automatic menu-state loads before resetting the timer. If loading
  fails, restart cleanly instead of leaving the old fight active.

Category objectives such as collecting all seven Dragon Balls or winning only
with Hercule still require review of the recording.

Download **OpenKai2.exe**, **OpenKai2-windows-x64.zip**, or **OpenKai2-Setup.exe**.
The original Budokai 2 USA ISO is required at every launch.
