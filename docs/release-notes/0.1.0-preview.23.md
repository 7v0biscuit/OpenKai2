This preview fixes a thread syscall mismatch that can leave the movie service
worker asleep while its file queue already contains data. ResumeThread and
WakeupThread now return the target thread ID on success, as expected by the
original CRI helpers. Negative errors and the scheduler's internal return
contract are preserved. A regression reproduces the sleeping worker before the
fix and executes the original compiled resume and wake acknowledgment callers.

Interlaced presentation now keeps odd and even field lines at their proper
vertical positions and interpolates missing lines. A stationary alternating-field
pattern reproduces the previous one-line shake. Checks cover field stability,
edges, odd heights, both read circuits, framebuffer origins, neighboring buffers,
black fades, and progressive output. No previous frame is retained.

The Windows publication gate requires both new regressions in the installed
application's self-test. Movie playback, title-screen boot, gameplay, and the
visible result of these corrections still need testing with the original USA
ISO. Launch with that ISO and retain the new startup log after testing.
