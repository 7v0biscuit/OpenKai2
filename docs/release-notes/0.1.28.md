# v0.1.28

Correct widescreen projection, complete story interaction commands, and reduce repeated palette work.

- Apply the USA camera’s horizontal 16:9 correction while preserving vertical
  scale and the original camera in other aspect modes. Keep 640×448 movies in
  their original TV proportions.
- Register both story interaction banks, including the confirmation handler
  reached after character selection. Exercise its readiness predicate and
  selection state across cached and uncached memory aliases.
- Reuse unchanged CLD=1 palettes. Invalidate reuse on palette writes from the
  CPU, image transfers and GPU draws, other palette loads, and reset.
- Log completed-frame rate, percentile interval bounds and long frames
  separately from window redraws, with periodic samples during play.
- Avoid repeated window blits while waiting for a completed game frame;
  continue polling input and closing or resizing the window normally.
- Ignore primitive settings in empty GIF tags and in REGLIST/IMAGE tags,
  retaining the in-progress primitive and its graphics context.
- Refine launcher navigation, typography, game details and setup summaries.
  Add a clear image preset that preserves display, pacing and save preferences.
  Group settings into padded sections, show disc and backup status throughout
  the launcher, and navigate with Ctrl+1 through Ctrl+4 from any page.

The original USA ISO is required. Host audio remains off. Complete story
progression, dialogue rendering, pod visibility, character poses and stable
60 FPS remain under validation. FSR 1 is spatial upscaling; FSR 3/4 and frame
generation remain unavailable.
