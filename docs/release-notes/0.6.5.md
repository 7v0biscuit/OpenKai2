# v0.6.5

Online play fixes.

- **Same version required online.** Games from different OpenKai2 versions
  could connect and then drift out of sync. They are now refused when joining,
  and the message shows both version numbers. Older versions can't join
  v0.6.5 rooms.
- **Smoother rollback.** The game that runs ahead now slows down by about
  2 ms a frame until both games are level, instead of pausing up to three whole
  frames at once, and it checks three times as often. It can also run 10
  frames ahead instead of 8 before waiting for the other player, so a late
  packet causes fewer stalls and frame drops.
