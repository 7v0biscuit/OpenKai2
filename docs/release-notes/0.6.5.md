# v0.6.5

Better performance on older PCs and online play fixes.

- **Lighter defaults on older PCs.** With **Auto** internal resolution the game
  now starts at Native on integrated GPUs or about 2 GB of graphics memory, and
  at no more than 2x on about 4 GB cards such as a GTX 1050 Ti or with 8 GB of
  system memory or less. Before, a 1080p screen always started at 3x. This also
  uses much less graphics memory.
- **Steadier frame rate in busy scenes.** When the game sends graphics work
  faster than the GPU thread can draw it, the game now waits only until the GPU
  thread picks up its next batch. Before, it waited for all queued drawing to
  finish, leaving both threads idle in turn and causing drops in heavy fights.
- **Frames shown sooner.** The game window now shows each frame as soon as it
  is ready instead of checking for one every millisecond, which used CPU time
  and added up to 2 ms of uneven delay.

- **Same version required online.** Games from different OpenKai2 versions
  could connect and then drift out of sync. They are now refused when joining,
  and the message shows both version numbers. Older versions can't join
  v0.6.5 rooms.
- **Smoother rollback.** The game that runs ahead now slows down by about
  2 ms a frame until both games are level, instead of pausing up to three whole
  frames at once, and it checks three times as often. It can also run 10
  frames ahead instead of 8 before waiting for the other player, so a late
  packet causes fewer stalls and frame drops.
