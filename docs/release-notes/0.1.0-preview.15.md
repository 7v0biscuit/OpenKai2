This preview fixes the unimplemented `sceSdTransToIOP` call reported by the
latest startup log. Stream cleanup now completes; the next stop occurs during
a 2 KiB EE-to-IOP sound transfer from the caller at `0x00146B10`.

The build now translates the original sound-transfer SDK routine instead of
calling the unimplemented named stub. It submits the original SIF DMA descriptor
and polls for completion in synchronous mode. Existing runtime SIF support
copies the payload into IOP RAM and reports completion.

The executable's self-test checks the logged payload, synchronous and
asynchronous transfer modes, memory aliases, rejected transfers, adjacent
memory, saved registers, and the original caller's continuation. Publication
requires this regression to pass in the installed Windows application.

The original USA ISO is required at every launch. Title-screen boot and gameplay
remain unverified. Retain `startup.log` when testing this development preview.
