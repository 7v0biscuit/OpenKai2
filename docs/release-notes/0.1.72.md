# v0.1.72

Launcher tab switching fixed, and a lighter game thread.

## Launcher

- Fixed dropdowns that sometimes didn't open, or ignored the click, right after
  switching tabs.
- Tab switching has no animation; the highlight moves straight to the new tab.

## Performance

- The PS2's sound processor now runs in short batches instead of after every
  few instructions. That roughly halves its cost and frees game-thread time on
  every stage, including stages with heavy particle effects. Sound is
  unchanged.
- Each presented frame copies only the part of video memory that is shown.
- `startup.log` now records, every five seconds, how often the game misses its
  frame deadline and how long rendering, DMA and graphics waits take. Send it
  from a slow stage to help find what's left.

The original USA ISO is required.
