# v0.1.13

Reduce vector arithmetic and geometry upload costs while retaining the runtime
header consistency fix and complete scene rendering checks from v0.1.12.

- Classify ordinary, nonzero vector arithmetic results without repeating the
  extended-precision calculation. The shortcut requires bounded finite input
  magnitudes; zero results, cancellation, extreme values, and exceptional
  inputs retain the original calculation. Numeric results, guest flags,
  instruction timing, and register dependencies remain unchanged.
- Copy contiguous VIF1 geometry uploads directly and expand packed signed or
  unsigned components with SIMD. Preserve vector-memory wrapping and untouched
  lanes. Masked, fill/skip, row-addition, truncated, and overlapping-source
  transfers retain the existing implementation.
- Compare 73,728 arithmetic cases and 1,664 VIF memory/register snapshots with
  the original runtime. Cover both extended-precision and binary64 arithmetic
  references. Upload all eight production-runtime triangle fixtures through
  VIF1 before executing their vector programs and checking rendered pixels.
  The vector component suite now contains 45 cases.

Three-run Windows binary medians under Wine measured 27–29% lower execution
costs in six arithmetic-heavy vector workloads and 90–97% lower costs in eight
contiguous upload workloads. All 16 vector execution states and eight upload
snapshots matched the previous runtime. These are synthetic kernel timings;
they do not establish retail frame rates.

Host audio remains disabled. The original USA ISO is required at every launch.
Complete matches and sustained 60 FPS remain unverified.
