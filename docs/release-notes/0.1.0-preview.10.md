This preview implements the scratchpad receive requested by `sceDmaRecvN` at
startup. The latest log gets past file-driver initialization and stops at this
previously unimplemented SDK function with a 16 KiB transfer into `0x003C4200`.

The receive now uses the runtime DMA controller to copy the actual scratchpad
bytes and update its address, count, and completion registers. Scratchpad status
reads preserve pending transfers. Unsupported receive devices still produce an
explicit error.

Regressions cover the retail transfer arguments, scratchpad wraparound, cached
and uncached destinations, SDK send/receive round trips, bounds, active transfers,
and completion polling. The installed executable's self-test also executes the
original compiled copy caller. Publication requires these checks to pass on
Windows alongside installation, portable launch, and uninstall checks.

The original USA ISO is required at every launch. Full game boot and gameplay
remain unverified; retain the startup log when testing this development preview.
