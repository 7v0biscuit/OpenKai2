# v0.3.9

Faster launcher scrolling.

- Scrolling no longer rebuilds the whole page layout on every wheel step. The
  page's controls simply move with it, and dropdowns are no longer re-measured
  each time.
- The page is kept as a ready-drawn image until something on it changes, so a
  scroll step copies the visible part and redraws only the header, dock and
  footer instead of drawing the entire page twice.

Both players need v0.3.9 to play together online.

Download **OpenKai2.exe** for the portable app, **OpenKai2-windows-x64.zip** to
extract manually, or **OpenKai2-Setup.exe** to install. The original Budokai 2
USA ISO is required at every launch. Checksums are in **SHA256SUMS.txt**.
