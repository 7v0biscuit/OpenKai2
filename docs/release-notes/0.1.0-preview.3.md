Fixes SPU2 transfer status during sound-driver initialization. Disabling DMA now
clears the completion latch, allowing the guest's reset-status poll to finish.
Both sound cores and byte, halfword, and word register writes are covered by
regression checks, including a sequence executed by the IOP interpreter.

The startup log now records bounded IOP state samples while waiting for an RPC
server. These identify the IOP instruction and sound-register state if CRI's
startup server remains unavailable.

The original Budokai 2 USA ISO is required at every launch. Title-screen boot
and gameplay remain unverified; this release addresses a reproducible sound
register bug found while investigating the latest startup log.
