# v0.1.83

Fix clipped text in the launcher's Splits panel.

- TIME, SEGMENT and BEST SEGMENT use untracked text drawing so Windows does not
  clip their final letters when right-aligning them.
- Column headings remain aligned with their times. BEST SEGMENT wraps when the
  column is too narrow for one line.

Includes the category profiles and timing controls from
[v0.1.82](https://github.com/7v0biscuit/OpenKai2/blob/main/docs/release-notes/0.1.82.md).
