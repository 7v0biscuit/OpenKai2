# v0.1.82

Speedrun category profiles and readable timing rules in smaller launcher windows.

## Speedrun categories

- Added World Tournament profiles for Novice, Adept and Advanced, plus All
  Dragonballs, Hercule Only and NG+ (Very Hard). Each profile keeps separate
  splits, personal bests and attempt history, including its Z difficulty variants.
- Dragon World profiles retain automatic start, battle splits and finish timing.
  Collection, character-win, equipment and difficulty requirements still need
  review against the recording.
- World Tournament uses manual timing: F9 starts/restarts, F10 records an
  intermediate round and F11 finishes. Tournament times display milliseconds;
  Permadeath is disabled. Automatic Tournament transition detection is not included.
- The selected category's rules appear in the launcher. Native OpenKai2 is not
  currently a listed speedrun.com platform; local records do not establish
  leaderboard eligibility. See [Speedrun mode](https://github.com/7v0biscuit/OpenKai2/blob/main/docs/speedrun.md).

## Launcher

- Timing rules scroll instead of being cut off by the footer.
- Split columns, headings, selected-split text and summary times stay inside their
  panels, including at the minimum window size.
- Empty split lists no longer cover their guidance text.
- Expanded category choices persist across restart without resetting preferences.

## Validation

Category timing, independent records, millisecond formatting and preferences are
covered by component checks. Native Windows interaction checks cover category
selection, split editing, rule scrolling and compact window layouts.

Existing game/runtime fixes from [v0.1.81](https://github.com/7v0biscuit/OpenKai2/blob/main/docs/release-notes/0.1.81.md)
are retained. Full Dragon World completion and consistent hardware frame rates
remain unverified.
