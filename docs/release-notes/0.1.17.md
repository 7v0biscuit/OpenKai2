# v0.1.17

Add GPU rasterization and restore missing pause-menu callbacks.

- Enable an OpenGL 4.3 compute renderer automatically, with ordered tile batches,
  bounded asynchronous submission, direct/indexed textures, filtering, blending,
  fog, alpha/depth tests, and 32-, 24-, and 16-bit color/depth targets.
- Preserve VRAM ordering across uploads, readbacks, palette loads, target changes,
  and presentation. Use the CPU compatibility path for feedback, overlapping
  targets, scan masking, and other unsupported states.
- Add `--renderer=auto|gpu|cpu`, `OPENKAI2_RENDERER`, `--gpu-self-test`, and renderer
  activity diagnostics. See [GPU rendering](../graphics.md).
- Register the pause-menu method bank and installed continuations, including the
  missing open callback. Verify all 21 original descriptors and execute 513
  bounded original callback/caller cases.
- Compare actual GPU output against complete software VRAM across 256 material
  states, 104 format states, 65,536 integer pipeline draws, and 576 point/line
  draws. Include transfer/coherence, VRAM replacement, real VIF/PATH1 geometry,
  and asynchronous failure checks. Linux CI requires successful GPU dispatch.

The original USA ISO remains required at launch. Host audio remains disabled.
Complete matches, hardware GPU performance, and sustained 60 FPS remain
unverified. The GPU checks use Mesa on Linux and Windows under Wine.
