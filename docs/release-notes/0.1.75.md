# v0.1.75

A Vulkan renderer, Z1/Z2/Z3 CPU difficulty and stricter permadeath.

## Graphics

- **Vulkan (GPU)** is a new choice under Settings > Renderer. It runs the same
  GPU renderer through Vulkan and falls back to OpenGL if Vulkan cannot start.
  Automatic still uses OpenGL.

## CPU difficulty

- Settings > Game > **CPU difficulty** adds Z1, Z2 and Z3 above the game's own
  levels. **F6** cycles them in game.
- Every Z level runs the strongest CPU behaviour in every fight. The CPU also
  hits harder, takes less damage and builds Ki faster, more so at each level.
- Z levels are off in speedrun mode and online. See `docs/cpu-difficulty.md`.

## Speedrun mode

- Permadeath ends the run on any Dragon World fight that is not won, by any
  character: knock outs, time outs and draws. Skipping a fight's ending no
  longer lets a loss through to a retry, and losses count in a Dragon World
  loaded from a save.
- **GAME OVER** shows before the game returns to the main menu.
- The run log says how each fight was lost, and without permadeath the run
  checks row counts fights lost.

The original USA ISO is required.
