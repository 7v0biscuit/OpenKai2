# v0.1.59

Better mod and import tools.

## Mods page

- **What a mod adds**: choose a mod in the load order and the right side lists
  its characters (name, ID, whose moves, which spot), stages and file counts.
  The load order also counts each mod's characters.
- **Rename**: type a name in the box beside Create mod, then press Rename. The
  folder keeps its name.
- **Delete mod**: removes the mod's folder after asking.
- **Remove**: removes one character or stage from a mod, with the files only
  it used. The character ID or stage is free again.
- The disc reports folder is no longer listed as a mod.

## Import tool

- **Last disc** reloads the last disc you imported from, so the Budokai 3 ISO
  doesn't need browsing for each time.
- Characters and models you have already imported are marked with the mod
  that holds them.
- The Save panel says how many more characters fit.
- **Special moves for every added character**: added characters past ID 40
  (when IDs 1, 13, 14 and 19 are taken) had no special moves. The game now
  reads their base character's move effects and hair, so their specials work.
- **Stage import from Budokai 3**: choose a Budokai 3 disc, then the Stages
  tab, a stage, and which of Island B, Town B, R&R Base B or Snow B it
  replaces. Those four are copies of other stages, so no stage is lost.
  Choose that stage on the stage select screen to play the imported one; the
  select screen still shows its old name and picture. Checked by unit tests,
  not yet in game.
- Clearer wording across the launcher.

Not fixed yet: in Dragon World the character can walk off screen, and the
dialogue text and the Yes/No prompt after character select are invisible.

The original USA ISO is required.
