Battle startup callbacks and streamed PCM audio support for Windows x64.

## Changes

- Register all eleven callbacks in the battle initialization table.
- Send SPU2 AutoDMA PCM to a 48 kHz stereo host stream and correct its DMA completion timing.
- Cache IOP import decoding with invalidation after guest code or table changes.
- Process triangle coverage in groups of four pixels while preserving existing rendering results.

## Downloads

| Package | Use |
| --- | --- |
| **OpenKai2-Setup.exe** | Per-user installer with Start-menu shortcuts. |
| **OpenKai2.exe** | Single-file portable launcher; no installation required. |
| **OpenKai2-windows-x64.zip** | Application and runtime DLLs for manual extraction. |
| **SHA256SUMS.txt** | SHA-256 checksums for the three packages. |

Requires Windows 10/11 x64, an SSE4.1-capable CPU, and your original **Budokai 2 USA ISO** at every game launch. Game files are not included. The executables are unsigned.

## Known issues

Battle loading reaches versus level selection, then stops at another missing battle callback (`0x001D21D0`). Frame rates remain low and unstable. PCM playback is audible, but audio quality and synchronization need further work. Complete matches and stable 60 FPS are not supported by the current evidence.

The existing Windows packages are preserved from the previous publication; this release name and repository cleanup do not change the binaries. Their internal version remains `0.1.0-preview.37`.

Windows packaging checks passed for the portable launcher, installed application, full component self-test, ISO rejection, and uninstall. These checks do not establish full retail gameplay.
