# v0.1.74

An accurate FPS counter and better frame timing.

## Game

- The FPS counter counts the new game frames that reach the screen. Before, it
  counted window redraws and could show far more than the game produced.
- Frame waits use a high-resolution Windows timer, so frames start on time even
  when the system timer is coarse.

## Diagnostics

- `startup.log` records how busy the graphics thread is, how much of that is
  spent on draws and batches, and how far frame waits overshoot. A log from a
  slow stage shows where the time goes.

The original USA ISO is required.
