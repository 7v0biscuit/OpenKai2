Restore the character aura callbacks and remove palette-sampling overhead in Windows builds.

## Changes

- Include all six original aura-update callbacks and the 576 bounded cases covering both character selectors, matrix updates, progress, completion, and saved registers.
- Carry prepared palette colors in each draw closure rather than reading a thread-local pointer for every pixel. Raster workers share that draw's immutable palette directly.
- Keep the general texture sampler free of the additional palette-pointer lookup. Preserve coordinate wrapping, perspective division, filter-read order, interpolation, and texture-cache behavior.
- Retain palette cache diagnostics, the small-draw fallback, and all 50 serial/parallel palette reference fixtures covering fourteen draws each.

Windows binaries measured roughly 14–20% lower median draw times on visible serial fixtures with reusable palettes against the earlier renderer. These three-run synthetic measurements execute native Windows code under Wine; all VRAM hashes matched. They remove the regression found in the preceding palette implementation, but do not establish native Windows game frame rates. Parallel timings remain mixed. Frequently changing palettes can still add overhead on tiny draws.

## Status

The aura entries address the reproduced missing call during battle setup. Complete battle loading, gameplay, and stable 60 FPS remain unverified. Movie decoding and audio are unchanged.

The original Budokai 2 USA ISO is required at every game launch. Game files are not included.
