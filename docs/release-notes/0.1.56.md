# v0.1.56

The v0.1.55 change did not fix the black and blue Budokai 3 bodies, and it was
wrong: the new reports show Budokai 2 sets the draw-record bit in only 27 of
Supreme Kai's 55 draw records and in none of Krillin's 50, and Krillin draws
fine. It is a per-model setting, not what turns the bodies black, so forced
imports no longer set it. They keep the material flag from v0.1.52.

What we know: the version that puts the Budokai 3 textures on the wearer's own
Budokai 2 body (D) draws right; the whole Budokai 3 model does not. Your
screenshot shows the eyes and outlines but every other colour wrong, which
looks like textures drawn with the wrong palettes. **Compare 4 versions
(test)** now adds four new versions to tell apart whether the Budokai 3 body
or its texture pack is to blame:

- **E**: the Budokai 3 body with all its textures, repacked the way D packs
  them.
- **F**: the wearer's own Budokai 2 body with all those textures (colours may
  land in the wrong places; what matters is whether they show at all).
- **G**: the Budokai 3 body with D's textures, renumbered to match.
- **D**: as before, the wearer's own body with the Budokai 3 textures.

Please add a Budokai 3 character this way (it needs a Budokai 2 character it
fits, for example Budokai 3 Goku on Goku) and say which of E, F, G and D show
colours.

Not fixed yet: in Dragon World the character can walk off screen, and the
dialogue text and the Yes/No prompt after character select are invisible.

The original USA ISO is required.
