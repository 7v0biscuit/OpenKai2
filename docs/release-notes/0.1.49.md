# v0.1.49

Budokai 3 characters' textures on Budokai 2 bodies, without the black.

The v0.1.48 comparison showed that Budokai 2 draws Budokai 3 textures
correctly on a Budokai 2 body, while every version with the Budokai 3 mesh is
drawn black. So importing a Budokai 3 model now brings over its textures and
puts them on the wearer's own Budokai 2 body, with that character's moves,
animations and voice. You get Budokai 3's colours and details on the Budokai
2 shape.

- Which characters a model fits now depends on its textures: the wearer's
  textures must have the same formats and sizes, in order, as the model's
  first ones, so they land in the right places. Extra Budokai 3 textures are
  left unused. The list still says who each model fits, and Import stays off
  when the chosen character doesn't.
- **Compare 4 versions (test)** stays, to check other models.

Limits:
- Only textures come over. Budokai 3 shapes (new hair, outfits or bodies)
  need the Budokai 3 mesh converted, which is not done yet: Budokai 2 draws
  those meshes black.
- Characters imported with v0.1.48 or earlier keep the whole Budokai 3 model
  and stay black; import them again.

Not fixed yet: in Dragon World the character can walk off screen, and the
dialogue text and the Yes/No prompt after character select are invisible.

The original USA ISO is required.
