# v0.3.1

More groundwork for rollback netcode.

- Rollback snapshots are much faster. They leave the picture out, since
  replayed frames draw it again, and compare memory on several CPU cores. In
  testing, a snapshot of a fight takes about 1.4 ms on a four-core PC.
- Rolled-back frames replay as fast as the PC allows, and their sound is
  dropped, so a correction is silent.
- Replays still match the original frames exactly in the in-game check.

Matches still run in lockstep; prediction and correction in real matches are
the next step. Both players need v0.3.1 to play together.

Download **OpenKai2.exe** for the portable app, **OpenKai2-windows-x64.zip** to
extract manually, or **OpenKai2-Setup.exe** to install. The original Budokai 2
USA ISO is required at every launch. Checksums are in **SHA256SUMS.txt**.
