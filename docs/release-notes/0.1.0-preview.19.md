This diagnostic preview addresses the latest log's misleading `gs=0` report.
Normal 32- and 64-bit GS display-register writes now increment that counter.
The previous movie callback exception is absent from the supplied log; DMA and
GIF activity continue until the window closes after about four minutes.

Startup reports now include the latched frame's dimensions, framebuffer source,
nonblack pixel count, RGB hash, drawing contexts, and recent draw/transfer
events. A bounded 512-event ring supplies that history. Four snapshots at the
original movie wait record the Sofdec interface/backend state and raw display
registers. Guest-memory inspection runs on the EE executor; reports do not
change waits, player state, or drawing commands.

The self-test renders the game's original opaque white and black fade packets
through DMA, GIF, the CPU rasterizer, and host presentation. It checks viewport
pixels, frame replacement, graphics reports, and the corrected register counter.
The installed Windows release must pass this regression before publication.

This preview does not establish a fix for blank retail output. Movie playback,
title-screen boot, and gameplay remain unverified. Launch with the original USA
ISO, leave the window open for at least 60 seconds, then retain `startup.log`.
