# v0.5.5

Per-tag name effects, channel links, new [TTV] and [YT] keys, steadier player
names and a much lighter launcher.

- **New [TTV] and [YT] keys.** Both tag keys were replaced. Key files issued
  before this release no longer work; ask the developer for the new file.
- **Effects for every tag.** Each tag now has its own animated name effects:
  [TTV] stream pulse, live glow and purple wave; [YT] red shimmer, subscribe
  pulse and spotlight; [ToB] ember, storm and toxic wave. [DEV] keeps its five.
  A profile can only use its own tag's effects, and every launcher checks the
  tag's signature before showing one.
- **Tag colors and effect rings.** The tag label is drawn in the tag's color,
  and avatars of players with an effect get an animated ring to match.
- **Channel links.** Tagged profiles can add a Twitch, YouTube or Kick link.
  It is signed with the tag's key, and other players see an **Open channel**
  button on that player's profile.
- **Picture framing fixed.** Choose **Fill the circle**, **Fit the whole
  picture**, **Fill, keep the top** or **Zoom in**. The choice saves right away
  and updates your shared card.
- **Player names no longer blink.** Rows in Players and Friends could briefly
  go blank while names animated. Rows are now drawn in one step.
- **Much lighter launcher.** Animated names redraw only themselves instead of
  the whole page, and the profile check is no longer repeated for every row.
  The Online and Profile pages use a fraction of the CPU they did.
- **Fixes.** Hidden controls no longer reappear when a page scrolls, so the
  empty Rooms message stays visible. Players on an unknown version show
  **Other version** instead of a bare "V".

Both players need v0.5.5 to play together online.

Download **OpenKai2.exe** for the portable app, **OpenKai2-windows-x64.zip** to
extract manually, or **OpenKai2-Setup.exe** to install. The original Budokai 2
USA ISO is required at every launch. Checksums are in **SHA256SUMS.txt**.
