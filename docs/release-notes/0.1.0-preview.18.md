This preview fixes the missing Sofdec movie-volume method in the latest startup
log. Fade dispatch now completes; startup next stops when `0x002A4EF8` calls
the movie interface's `SetOutVol` method at `0x00186E88`.

Translation hints now cover all 14 methods in that interface. The build verifies
the original table and requires every method to resume at its own instruction.

The executable's self-test follows the original movie-to-ADX audio call chain
and checks volume, both pan channels, signed values, clamping, no-audio behavior,
status queries, saved registers, and adjacent memory. It also executes the
logged caller's table loads and indirect call through its return continuation.
Publication requires this regression to pass in the installed Windows application.

The original USA ISO is required at every launch. Movie playback, title-screen
boot, and gameplay remain unverified. Retain `startup.log` when testing this
development preview.
