# v0.1.15

Restore a missing actor-command callback and reduce vector arithmetic flag
processing costs.

- Register all 40 methods in the actor-command bank containing `0x001FB010`.
  An indirect call to this entry could otherwise stop the main guest thread.
  Verify the original table, complete method instructions, and indirect caller.
- Exercise the original orientation callback in 48 cases and the compiled
  command-selection caller in 120 cases. Check table selection, arguments,
  cached and uncached address aliases, stream positions, saved registers, and
  caller frames.
- Classify normal vector products and signed zero directly from normalized
  operand bits. Preserve the original extended-precision calculation for
  underflow and overflow boundaries. Simple bounded add/subtract/multiply
  zeros also avoid repeated arithmetic; product-sum cancellation keeps its
  original calculation.
- Retain the 73,728 original arithmetic cases and add 32 multiply-add/subtract
  pipeline snapshots covering repeated programs, signed zero, broadcast,
  Q/I operands, and cross lanes. The vector suite contains 46 cases.

Three alternating Windows binary measurements under Wine showed 12–17% lower
costs across eight multiply-add/subtract workloads. The original state, flag,
and timing hashes matched. These are synthetic vector timings and do not
establish retail game frame rates.

The original USA ISO remains required at launch. Host audio remains disabled.
Complete matches and sustained 60 FPS remain unverified.
