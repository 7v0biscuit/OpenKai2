# v0.1.69

Online matches start only after both players are connected, plus launcher and
audio fixes.

## Online

- Hosting or joining no longer starts the game straight away. Both launchers
  meet in the room first, check the version, password and connection, and
  measure the ping. Only then do both games start together.
- There is no port to set. The room uses port 7350 or the next free one, and
  the match uses the same port the other player already reached.
- Your controls work while the two games link up.
- **Close room** and **Cancel** stop waiting.

## Launcher

- Friends have their own list in the sidebar on every page. Pick one to invite
  or remove them, or double-click to invite.
- Discord activity is always on; the toggle is gone.
- Dropdowns show hover and open states, and the open list has a border.
- The selected tab slides when you switch pages.

## Audio

- Game audio plays through its own output with a larger buffer, to stop pops
  when the PC is busy.

The original USA ISO is required.
