# v0.1.12

Correct the v0.1.11 regression that could leave character, stage, and background
rendering absent while the UI remained visible.

- Use one complete public runtime header tree in the interpreter, enclosing
  runtime, translated game, checks, and precompiled headers. The previous build
  mixed vector class layouts differing by 32 bytes, corrupting embedded vector
  state and causing VIF1 programs to execute with VU0 semantics.
- Fingerprint the reviewed header tree to invalidate cached objects when its
  contents or include resolution changes. Preserve the vector scheduling and
  instruction-handler optimizations.
- Check compiled layouts before constructing the runtime. Windows packaging
  requires the new runtime integration self-test.
- Exercise the real VIF1 MSCAL/MSCNT callbacks and PATH1 triangle rendering
  across four reset/reupload cases. Verify eight rendered triangles, untouched
  surrounding pixels, and independent VU0/VU1 state during VU0 microprograms.
  The component suite now contains 43 cases; the original vector execution,
  pipeline timing, and floating-point references remain enabled.

The new integration test reproduces the previous failure and passes with the
consistent headers. It verifies a synthetic scene through the production
runtime. Complete retail scenes, matches, and sustained 60 FPS remain
unverified. Host audio remains disabled, and the original USA ISO is required
at every launch.
