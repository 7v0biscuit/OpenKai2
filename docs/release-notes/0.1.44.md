# v0.1.44

Disc reports show how character models are built, to loosen the Budokai 3
model check.

The v0.1.43 Budokai 3 report listed 175 character models. Budokai 3's own
Goku models range from 45 to 62 parts across his forms and costumes, and
Budokai 3 animates all of them, so a game's animations do not need every
model to have the same parts. The import tool's check, which asks for the
same parts linked the same way, is stricter than the games are and refuses
models that may well work.

The report now includes the structure of the first character's models (Goku
in both games), up to four of different shapes: each mesh header, each part's
row and the first bytes of each part's data. Comparing them should show how
parts attach to the skeleton, so the check can compare what the animations
actually use.

To continue, save the Budokai 3 and the Budokai 2 reports with this version
and send both. The Budokai 2 report must be saved again too: the last one was
from an older version and has no model list.

Not fixed yet: in Dragon World the character can walk off screen, and the
dialogue text and the Yes/No prompt after character select are invisible.

The original USA ISO is required.
