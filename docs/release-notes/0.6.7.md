# v0.6.7

- **Faster game start.** The launcher used to re-read and check the whole
  game ISO, several gigabytes, every time you pressed Play. It now remembers
  a disc it has already checked and only checks it again in full when the ISO
  or the extracted game files change. The game executable is still checked
  on every launch.
- **Smooth home screen.** The Wave home was drawing every icon through a
  fresh 4x supersampled image on every frame and rebuilding the whole galaxy
  background each frame, so it ran at about 30 FPS. Icons are now drawn once
  and reused, and the galaxy is refreshed a quarter at a time. The home screen
  takes about a quarter of the time it did per frame and holds 60 FPS with
  every background.
- **Better problem reports.** When the game closes, the launcher now copies a
  short summary of the game's log into launcher.log: build, graphics card,
  display settings, frame pacing, GPU waits, audio underruns and any errors.
  A launcher.log sent with a report now shows how the game actually ran.
- **Console-style home screen.** Titles, menu items, names and the clock use
  the Budokai 2 display font again, with Inter kept for descriptions. The
  header no longer shows a Dragon Ball, your level sits next to your name, the
  status line has a coloured light, and key hints are shown as keycaps.
- **Game cover.** Settings > Launcher > Game cover lets you pick any picture,
  for example a photo of your own box, to show as a large tile on the Play
  item of the home screen. Without one, Play shows the plain icon.
