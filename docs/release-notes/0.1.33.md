# v0.1.33

A simpler launcher layout, reversible character and stage unlocks, and Discord
activity for the launcher and game. Includes the rendering, animation and audio
changes from v0.1.32.

- Refine page headings, spacing and the Play panel. Remove the duplicate
  sidebar status card and keep disc readiness in the page header.
- Keep Discord's activity switch visible on every page, with connection status.
  Saved choices apply to an already running game as well as future sessions.
- Add **Unlock all** to Saves. It unlocks the USA game's characters and stages
  in an existing progress save, retaining story progress, other inventory and
  preferences. A restorable memory-card backup is created before any change.
- Validate both save checksums and write changes through the same staged
  replacement used by save imports. Damaged and unsupported saves are rejected.
- Check the save codec and unlock flags against the original compiled game
  routines, in addition to backup, restore, native launcher and local Discord
  IPC tests.

For the Discord activity icon, upload the current EXE icon as the application's
`openkai2` art asset. The Discord desktop client must be running.

The original USA ISO is required. Unlocks do not complete story mode or grant
every skill capsule. Complete matches and consistent 60 game FPS remain
unverified.
