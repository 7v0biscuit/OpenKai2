Adds all eleven original battle startup stages, including the missing
`0x001B2560` entry reported after level selection. Validation covers the table,
original state copy/clear, and the logged indirect caller. Full retail matches
still need confirmation.

Adds 48 kHz stereo PCM output for the guest's SPU2 AutoDMA path. Transfer
interrupts now follow audio duration rather than ordinary memory-copy timing,
reducing excessive audio-driver wakeups. Device queues retain channel order,
bound overflow, and handle stream stops without reading guest RAM on the audio
thread. Existing Windows playback APIs are used; no separate driver installer
is needed. Compressed voice DMA remains outside the PCM path.

Adds `--audio-test`, which plays a quiet one-second tone and records device
initialization and callback delivery in `audio-test.log`. The headless Windows
test environment has no usable audio endpoint, so audible Windows playback
and complete retail audio remain unverified.

Caches repeated IOP import decoding with page-based invalidation. The isolated
lookup benchmark improved from 38.59 ms to 1.43 ms per 100,000 calls. Triangle
coverage now tests four pixels at once while retaining the previous VRAM
output. These component improvements do not establish game FPS. **Constant
60 FPS across all screens remains unverified.**

renderer, PCM, import-cache, movie, input, and persistent-save checks before
