# v0.1.38

Added characters no longer push anyone off the select screen.

- Share a spot: an added character can share a select-screen spot with the
  character already there. Press R2 (Right Shift on the keyboard) on the spot
  to switch between them. This is the default when you add a character in the
  import tool. It changes only the game's data, not its code.
- Add new spots (experimental): an added character can get a spot of its own
  on the select wheel, before Random. The select screen's code now reads its
  cell count from OpenKai2. Without a mod that adds spots, it uses the original
  values, so the unmodded screen is unchanged. New spots are always unlocked
  and borrow the portrait of a spot you choose.
- Fix the select screen for filled character IDs: they get their base
  character's costume count, which used to be 0. The screen can also open with
  the cursor on them. IDs 37 and up preview as their base character instead of
  Gotenks.

Limits:
- There are 14 unused character IDs, so 14 added characters at most.
- New spots borrow an existing portrait.
- The select-screen changes are checked by unit tests against the USA
  executable's tables, not yet in game. Please try them and report what you
  see, with `startup.log`.

Not fixed yet: in Dragon World the character can walk off screen, and the
dialogue text and the Yes/No prompt after character select are invisible.

The original USA ISO is required.
