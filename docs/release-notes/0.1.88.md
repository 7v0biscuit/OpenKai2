# v0.1.88

Automatic World Tournament timing, three new Z difficulties and a speedrun fix.

- Speedrun categories that copy your save (NG+, NG+ (Very Hard), All
  Dragonballs, Hercule Only and the Tournament profiles) failed to start on
  Windows with "cannot copy: File exists". The memory card copy now works.
- World Tournament runs are timed automatically. The timer starts when you
  confirm Normal or Custom, each match won is a split, and the run finishes on
  the final match when the champion scene appears. Returning to the tier select
  or the main menu ends the attempt. F9, F10 and F11 still override the timer.
- New CPU difficulties Z4, Z5 and Z6. Higher levels hit harder, take less
  damage and build Ki faster; the CPU starts with more Ki, and from Z4 it slowly
  recovers health during a fight. Each Z level keeps its own speedrun splits.

Download **OpenKai2.exe** for the portable app, **OpenKai2-windows-x64.zip** to
extract manually, or **OpenKai2-Setup.exe** to install. The original Budokai 2
USA ISO is required at every launch. Checksums are in **SHA256SUMS.txt**.
