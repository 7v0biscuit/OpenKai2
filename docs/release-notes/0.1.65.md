# v0.1.65

Budokai 3 stages load, and added characters have voices.

- Budokai 3 stages no longer freeze the game. Their effects pack held 641
  slots of particle effects and animated stage objects, where Budokai 2
  expects a short pack with the effect texture first. The import tool now
  builds that short pack, so the stage loads and fights run on it, without
  its particle effects and moving objects. Tested in a fight on Budokai 3's
  Town. Stages imported before v0.1.65 are skipped with a note; delete them
  on the Mods page and import them again.

- A character added past the original roster now speaks with its base
  character's voice. The voice player (`0x24A0C0`) reads three per-character
  voice tables, which cover IDs 0 to 31 and 0 to 35; IDs past them read
  whatever followed the tables. Those reads now take the base character's row.
- The roster copies the third voice table (`0x378850`, IDs 0 to 31) as well,
  for added characters within it.

Not fixed yet: in Dragon World the character can walk off screen, and the
dialogue text and the Yes/No prompt after character select are invisible.

The original USA ISO is required.
