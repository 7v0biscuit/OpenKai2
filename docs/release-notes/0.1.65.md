# v0.1.65

Clear music, speedrun mode, Budokai 3 stages load, and added characters have voices.

- Music and movie audio are clear. They are stereo ADX streams, and the game
  decoded them without ADX's prediction filter, so every sample was a raw
  step and the music sounded harsh and noisy. The filter's coefficients are
  computed with `SQRT.S`, which on the PS2's CPU takes its operand from a
  different field than on other MIPS CPUs; the translated code took the
  square root of the wrong register and the coefficients came out as zero.
  All 15 `SQRT.S` instructions in the game now read the right register,
  including ones in vector-length and camera code.

- Speedrun mode (Settings → Speedrun) times Dragon World under the
  speedrun.com rules: Any% or NG+. The timer starts when Dragon World starts
  and stops on the last hit of Kid Buu. Optional permadeath restarts the game
  and the timer after a game over in Dragon World. Mods are off during runs.
- Overlay with automatic splits on each battle won: run timer, split list with
  differences to your best run, segment timer, previous segment, possible time
  save, best possible time, sum of best, personal best, PS2 time, attempts and
  run checks. **Customize overlay…** picks the items, corner, size, background
  and split count, with a preview. F7 hides it, F8 resets.
- Splits are saved after every run to compare later runs. Each session also
  writes a checksummed log for moderators: executable, ISO and game data
  hashes, settings, and every run event. Runs are flagged for modified game
  data, a game running faster than a PS2, clock speed hacks, debuggers or
  memory editors.
- LiveSplit: when its server is running, OpenKai2 starts, splits and resets it
  and sends PS2 time as game time.
- An FPS counter can be shown in the corner.
- Two more upscalers: Lanczos (sharper than bicubic) and Sharp pixels (crisp
  square pixels at any window size, without nearest scaling's shimmer).
- The GPU renderer logs why it falls back to CPU drawing
  (`[renderer:fallback]` in startup.log), so frame drops on a stage or effect
  can be traced to the draw that causes them. The snow stage was checked: its
  snow draws use formats the GPU renderer supports.

- Budokai 3 stages no longer freeze the game. Their effects pack held 641
  slots of particle effects and animated stage objects, where Budokai 2
  expects a short pack with the effect texture first. The import tool now
  builds that short pack, so the stage loads and fights run on it, without
  its particle effects and moving objects. Tested in a fight on Budokai 3's
  Town. Stages imported before v0.1.65 are skipped with a note; delete them
  on the Mods page and import them again.

- A character added past the original roster now speaks with its base
  character's voice. The voice player (`0x24A0C0`) reads three per-character
  voice tables, which cover IDs 0 to 31 and 0 to 35; IDs past them read
  whatever followed the tables. Those reads now take the base character's row.
- The roster copies the third voice table (`0x378850`, IDs 0 to 31) as well,
  for added characters within it.

Not fixed yet: in Dragon World the character can walk off screen, and the
dialogue text and the Yes/No prompt after character select are invisible.

The original USA ISO is required.
