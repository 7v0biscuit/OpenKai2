Fixes the missing character-animation callback at `0x002AEAC0` reported when
versus characters load. The original scene dispatcher now reaches the original
frame update and model-render tail call. Both character slots, frame wrapping,
clamping, caller state, and memory bounds are checked with translated code.
A complete retail versus match still needs confirmation.

Large independent textured triangles now use up to four CPU workers. Opaque
source-over pixels avoid unnecessary framebuffer reads, general blending uses
SSE4.1, and eligible zero-alpha sprite passes avoid unused texture sampling.
Feedback, stale sampled pages, and color/depth dependencies retain serial
behavior, including the final cached texture page. Triangle timing records
help identify remaining work in retail logs.

Isolated development-host measurements show about 2.3–2.6 times faster large
triangle draws and 4.5 times faster zero-alpha sprite passes, with matching
complete VRAM hashes. These are component timings, not measured game FPS.
Stable 60 FPS across movies, menus, and matches remains unverified.

Validation includes 12,288 scalar blend comparisons, 48 triangle snapshots in
serial and parallel, 64 sprite comparisons, the original versus caller, and
existing movie, DMA, input, and persistent-save regressions. The Windows
workflow checks the installed application's complete self-test before release.

The original USA ISO remains required at every launch. Existing disc-cache
and memory-card directories remain usable. Download the EXE, ZIP, or installer
below; do not delete the `mc0` directory when updating.
