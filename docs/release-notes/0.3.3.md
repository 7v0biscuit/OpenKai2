# v0.3.3

The launcher now keeps each repaint intact when Windows delivers resize,
navigation or DPI changes during drawing. This fixes an intermittent access
violation while switching pages, changing monitor scale or managing profiles.
Scroll copies also stay within the canvas when the client area is very small.
Focus changes take effect immediately, so a delayed deactivation cannot close
a dropdown opened after returning to the launcher.

This update includes the console-style dock, thirteen coordinated color themes,
Budokai-inspired lettering, profile recovery, notification inbox and keyboard
help introduced in v0.3.2. The header action search bar has been removed;
Ctrl+K still opens quick access.

Windows release publishing now requires the component checks on both main and
the release tag, in addition to portable, installer and updater validation.

Music playback and mod tools remain in development.

Download **OpenKai2.exe** for the portable app, **OpenKai2-windows-x64.zip** to
extract manually, or **OpenKai2-Setup.exe** to install. The original Budokai 2
USA ISO is required at every launch. Checksums are in **SHA256SUMS.txt**.
