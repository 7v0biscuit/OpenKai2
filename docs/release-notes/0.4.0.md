# v0.4

Run-ahead and online matches that fix themselves.

- **Run-ahead** (Settings > Game > Run-ahead: off, 1 or 2 frames) hides the
  game's own response delay. Each frame OpenKai2 runs one or two frames ahead
  instantly and silently with your current buttons, shows the newest one, then
  rewinds, so you see your moves one or two frames sooner. It needs a fast PC:
  if recent frames start arriving late it lowers itself by a frame, and turns
  off if needed, so it never slows the game down. It pauses during loading,
  memory card saves and movies, and is off online and in speedrun mode.
- **Online matches recover from going out of sync.** When the memory check
  finds the two games differ, the host sends its full game state and memory
  card and the other game carries on from it, so the match continues instead
  of drifting apart. This happens at most three times per match.
- Online sync checks now run on every scheduled frame, even while rollback is
  still correcting it, so a difference is caught within two seconds.
- Fixed the game stopping with "the memory card is in use" when run-ahead or
  an online match took a snapshot while the game was reading or writing the
  memory card. A save state key press now waits until the card is idle.

Both players need v0.4 to play together online.

Download **OpenKai2.exe** for the portable app, **OpenKai2-windows-x64.zip** to
extract manually, or **OpenKai2-Setup.exe** to install. The original Budokai 2
USA ISO is required at every launch. Checksums are in **SHA256SUMS.txt**.
