This preview fixes the earlier startup stall reported with Preview 23, where
drawing stopped before the logos and the movie player remained inactive.

ChangeThreadPriority and its interrupt-safe variant now return the previous
priority on success. The original CRI critical-section code saves that result
and restores it on exit. Returning zero left the main thread at its temporary
priority because restoring priority zero is invalid. Negative errors and the
scheduler's internal return contract are preserved.

The expanded regression executes nested original critical sections, verifies
restored priority and saved registers, then runs sixteen service/sleep cycles
through all four compiled CRI workers and the actual VBlank callback. Native
movie preparation callbacks must continue advancing their service counter.
The installed Windows application's self-test must pass this regression before
publication. The priority failure is reproduced on the previous runtime.

The test uses a single preparation driver without disc assets. Visible logos,
movie decoding, title-screen boot, and gameplay still need local ISO testing.
The original USA ISO is required at every launch.
