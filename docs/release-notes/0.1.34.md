# v0.1.34

Steady music tempo, less GPU stalling in presentation, an Alt+Tab-friendly
borderless mode and correct formatted text.

- Keep the music tempo steady when the game runs slightly below full speed.
  The time-stretcher locked to full speed whenever the game was within 8% of
  it, so at the 93% speed in the last log the audio queue drained, and the
  tempo was then cut towards half speed until it refilled. Music swung
  between those tempos all the time. The tempo now follows the game's audio
  rate smoothly and only reacts strongly when the queue is nearly empty.
- Read the displayed frame back from the GPU without blocking drawing. The
  frame on screen was copied back while holding the renderer lock, so the GS
  thread could not submit draws until the GPU finished. In the last log the
  game waited on the GS for 21 of 206 seconds, partly because of this.
- Borderless fullscreen no longer stays on top of other windows, so Alt+Tab
  works.
- Read the game's variadic arguments from 8-byte slots. Every `printf`-style
  argument after the first was read from the wrong place, and formatted
  strings were cut at 255 characters.
- Write the result of each launcher job, such as Unlock all, to
  `launcher.log`.

Not fixed yet: in Dragon World the character can walk off screen, and the
dialogue text and the Yes/No prompt after character select are invisible.

The original USA ISO is required. These changes are verified by unit, GPU
comparison and audio tests and need in-game confirmation.
