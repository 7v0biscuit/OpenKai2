# v0.1.53

The Stages and Movesets tabs of the import tool now show something.

- **Movesets**: with Budokai 2 as the source (**Game disc**), choose whose
  moves on the left and whose body on the right. The new character uses the
  first character's moves, animations and move effects and wears the second's
  costume models, in a shared spot or a new one. Nobody leaves the select
  screen. When their skeletons differ the tool says so, since the body may
  move oddly.
- **Stages**: the tab lists the stages on a Budokai 2 or Budokai 3 disc, with
  the files each uses. Budokai 3's stage table is now mapped: 17 stages, whose
  files are the same versions as Budokai 2's, packed in two archives each.
  Importing a stage still needs the stage select screen mapped, so it isn't
  possible yet.
- **Capsules** are not mapped in any game yet; the tab says so.
- Budokai 3 and Infinite World movesets are a newer file version than Budokai
  2 reads, so they can't be imported; the tab says so.

Still waiting on an in-game check: whether v0.1.52 shows forced Budokai 3
characters with their colours.

Not fixed yet: in Dragon World the character can walk off screen, and the
dialogue text and the Yes/No prompt after character select are invisible.

The original USA ISO is required.
