# v0.1.76

Speedrun categories for Z difficulties, a customizable overlay, map-health
permadeath and cleaner music.

## Speedrun mode

- Z1, Z2 and Z3 can be used in speedrun mode. Each one is its own category
  with its own splits ("Any% Z3"), shown on the overlay and in the run log, and
  the difficulty is locked for the run. The Speedrun page has its own CPU
  difficulty choice.
- A **Splits** panel on the Speedrun page changes, adds or removes saved split
  times and resets the best run.
- The overlay page adds colors for text, times ahead, times behind and best
  segments, and shows times to hundredths, tenths or whole seconds.
- Permadeath ends the run only when a fight is lost and a character loses
  health on the Dragon World map. Loading Dragon World, changing maps, story
  scenes and enemy health no longer end a run.

## Game

- Music no longer sounds doubled or pops when the game runs a little faster or
  slower than the sound card. Small differences are absorbed without time
  stretching.
- Esc no longer closes the game.
- Lines and triangles skip 64-bit depth math on the GPU when a draw does not
  use depth, which helps particle-heavy scenes on GeForce cards.
- `startup.log` reports how long the GPU is busy and how long the game waits
  for it.

The original USA ISO is required.
