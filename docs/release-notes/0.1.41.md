# v0.1.41

Disc reports compare the file formats of Budokai 2 and Budokai 3.

The v0.1.40 reports showed:
- Budokai 3's character table starts at `0x447440`: 96-byte records in the
  order of its name list. Each record points at two lists of entries; the
  first holds a character's model files, one per form or costume (for Goku,
  `DATA_CMN.AFS` entries 264 to 268).
- A costume model is an `#AMB` pack of a mesh (`#AMO`) and its textures
  (`#AMT`) in both games. The mesh format has the same version in both, but
  Budokai 3's textures are version 2, which Budokai 2 never uses. Budokai 2
  uses versions 0 and 1.
- Animations (`#AMM`) have the same version in both games. Skeletons (`#BSK`)
  are version 3 in Budokai 2 and version 4 in Budokai 3.
- A 5 KB file every character has is the same size and layout in both games.

So a Budokai 3 costume would most likely need its textures converted before
Budokai 2 can show it. The report now also shows:
- up to three samples of every file format and version, up to 512 bytes
  each, so the texture and skeleton changes can be worked out;
- the whole Budokai 3 character table, from Goku on, and one more step of the
  data it points at.

To continue, save the Budokai 3 and Budokai 2 reports again with this version
and send both. Characters cannot be imported from Budokai 3 yet.

Not fixed yet: in Dragon World the character can walk off screen, and the
dialogue text and the Yes/No prompt after character select are invisible.

The original USA ISO is required.
