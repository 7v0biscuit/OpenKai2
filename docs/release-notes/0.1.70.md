# v0.1.70

Speedrun run checks that stay on, and small launcher improvements.

## Speedrun

- **Run checks** (category, permadeath and Verified, Flagged or Run over) are
  always shown while speedrun mode is on. They can't be turned off in the
  launcher or in `settings.ini`, and **F7** now hides everything else but them.

## Launcher

- The selected-tab slide follows your display's refresh rate and only redraws
  the sidebar, so it stays smooth on high refresh rate monitors.
- **Enter** adds a profile from the **New profile** box, joins the selected room
  from the password box and joins an address from the address box.
- **Esc** stops waiting in a room. **Ctrl+R** refreshes the room and player
  lists.
- The Rooms and Players lists show how many are open and online.

The original USA ISO is required.
